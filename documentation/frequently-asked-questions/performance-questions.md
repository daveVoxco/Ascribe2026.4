# Performance Questions

**What do I do if Ascribe is hanging up, takes a long time to apply codes, or is otherwise running slow?**

If you are working on a large study in Ascribe Coder, turn off "code duplicates." When code duplicates is selected, Ascribe compares each verbatim with every other verbatim in the question. With a lot of large verbatims, this function will noticeably slow the Coding Window.

Can you reach any other Internet addresses? Is the Internet running slow? (A sure fire way to know if it is your access or our server is to try a new Google search, like "foobar".)

**Is your PC running slow, generally?**

1. Ping the site and send to [support@goascribe.com](mailto:support@goascribe.com)
2. Run a Trace Route on the site and send to [support@goascribe.com](mailto:support@goascribe.com)
3. Call Ascribe support 513.241.9112 ext. 21

**Ping a site**

To reach your DOS prompt:

1. Left-click your windows start button
2. Choose Run
3. Type **cmd** into the Open: box

To ping the Ascribe website:

1. Type: **Ping app.goascribe.us** or  **Ping app.goascribe.eu**
2. Press **Alt**-**Print Screen** (hold both keys down at same time)
3. Paste into email and send to [support@goascribe.com](mailto:support@goascribe.com)

**Perform a trace route**

To reach your DOS prompt:

1. Left-click your windows start button
2. Choose Run
3. Type cmd into the Open: box
4. Type: tracert app.goascribe.us or app.goascribe.eu
5. Pres Alt Print Screen (hold both down at same time)
6. Paste into email and send to [support@goascribe.com](mailto:support@goascribe.com)
