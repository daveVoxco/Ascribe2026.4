# Translation and Transcription Questions

**My Transcription or Translation does not appear as an option in the Edit Question window; how do I resolve this?**

Check the Account Options (under Administrator) and make sure that you have Transcription or Translation selected as Question Tasks under the "Questions/Codebook options".
