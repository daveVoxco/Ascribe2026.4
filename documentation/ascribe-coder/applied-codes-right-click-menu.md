# Applied Codes Right-Click Menu

The applied codes right-click menu has the following options:

<table><thead><tr><th width="283.3333740234375" valign="top">Option</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top"><strong>When codes are or are not selected, these options are available:</strong></td><td valign="top"></td></tr><tr><td valign="top">Select</td><td valign="top"><p>Has these options:</p><ul><li><strong>This code in all responses –</strong> Selects and highlights the code in all of the responses displayed in the Response pane</li><li><strong>All responses with this code –</strong> Selects and highlights all responses displayed in the Response pane that have the code applied</li><li><strong>All codes in this response –</strong> Selects and highlights all of the codes applied to the response</li><li><strong>This code in the codebook –</strong> Selects and highlights the code in the Codebook pane</li></ul></td></tr><tr><td valign="top">Remove</td><td valign="top"><p>Removes the selected applied code(s) from a response:</p><ul><li><strong>This code –</strong> Removes the applied code from a response</li><li><strong>This code and all selected codes –</strong> Removes the applied code and any other selected codes from a response</li></ul><p>Codes removed from a response are highlighted red until the code is removed from the display.</p></td></tr><tr><td valign="top">Remove Last Codes Applied</td><td valign="top"><p>Remove Last Codes Applied is activated only when a code has been applied to a response. (If no codes have been applied in the session, the option is available but will not be active.)</p><p>The action will remove the last code applied to a response. If <a href="responses-settings.md#minitocbookmark4">Code Duplicates</a> is selected in the Responses Settings dialog, the code will be removed from the duplicate verbatim depending on the setting. See <a href="remove-last-codes-applied.md">Remove Last Codes Applied</a> for more information.</p></td></tr><tr><td valign="top">Show In Codebook</td><td valign="top">Highlights the code in the Codebook pane.</td></tr><tr><td valign="top"><strong>When codes are not selected, this option is also available:</strong></td><td valign="top"></td></tr><tr><td valign="top">Swap</td><td valign="top">Allows swapping of one code for another; see <a href="swap-codes.md">Swap Codes</a> for more information.</td></tr><tr><td valign="top"><strong>When codes are selected, these options are available:</strong></td><td valign="top"></td></tr><tr><td valign="top">Deselect</td><td valign="top"><p>Has these options:</p><ul><li><strong>All –</strong> Deselects and unhighlights all of the selected codes</li><li><strong>This code in all responses  –</strong> Deselects and unhighlights the code in all of the responses displayed in the Response pane</li><li><strong>All responses with this code –</strong> Deselects and unhighlights all responses displayed in the Response pane that have the code applied</li><li><strong>All codes in this response –</strong> Deselects and unhighlights all of the codes applied to the response</li></ul></td></tr><tr><td valign="top">Previous Selected</td><td valign="top">Allows user to find the next selected applied code <strong>above</strong> the current one. <strong>Screen scrolls up</strong> to the first selected applied code above the current one; the highlight of that code will flash yellow to bring attention to the response.</td></tr><tr><td valign="top">Next Selected</td><td valign="top">Allows user to find the next selected applied code <strong>below</strong> the current one. <strong>Screen scrolls down</strong> to the first selected applied code below the current one; the highlight of that code will flash yellow to bring attention to the response.</td></tr><tr><td valign="top">Swap</td><td valign="top"><p>Allows swapping of one or more codes for another; see <a href="swap-codes.md">Swap Codes</a> for more information. Has these options:</p><ul><li><strong>This code -</strong> Swaps this code for one selected in the codebook</li><li><strong>This and all selected codes -</strong> Swaps all selected codes for one selected in the codebook</li></ul></td></tr></tbody></table>
