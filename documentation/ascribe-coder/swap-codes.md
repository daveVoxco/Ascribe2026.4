# Swap Codes

Swapping codes allows you to replace codes automatically; there are two methods: drag/drop or  via a right-click option.

## Drag/Drop to Swap Codes <a href="#minitocbookmark2" id="minitocbookmark2"></a>

To swap codes:

* In the Response Pane, select a code or codes that have been applied to a response or responses. (The codes do not have to be the same.)
* Drag the appropriate code from the codebook to one of the selected codes.
* The Swap Codes dialog displays. Click the Swap Codes button to continue or click Cancel to ignore the swap.

## Right-Click Option <a href="#minitocbookmark3" id="minitocbookmark3"></a>

Swap Codes is a right-click option in the Response Pane, available only when a code has been applied to a response.

To swap codes:

* Select a code or codes that have been applied to a response or responses. (The codes do not have to be the same.)
* Select one code in the codebook. The swap will not work if a code is not selected in the codebook or if more than one code is selected in the codebook.
* Right-click one of the codes and select Swap>This code or Swap>This and all selected codes. The screen will look something like this:

![](https://static.goascribe.com/Help/swap_codes_01_071614.gif)

After you make a selection, a confirmation dialog displays, as shown below. Click the Swap Codes button to continue. Note that if you have [Code Duplicates](https://static.goascribe.com/Help/Responses_Settings.htm#Code_Duplicates) selected in the Responses Settings dialog, the duplicate responses will also be swapped, as shown below.

![](https://static.goascribe.com/Help/Swap_Codes_confirmation.gif)
