# Pager

The Pager dialog displays when you click the numbers below the Search Again icon.&#x20;

Use the Pager to move to specific pages by entering a number in the text box.

Use the forward arrow to move to the next page or use the last page arrow to display the last page of data.&#x20;

Use the backward arrow to move to the previous page or the first page arrow to display the first page of data.

To close the dialog, click the numbers below the Search Again icon.
