# Show Other Responses

All Responses for this Respondent is a right-click option in the Response Pane. The option displays all of the responses for the respondent, along with any codes that have been applied.

The dialog contains two tabs: List and Table. The List tab, as the name suggests, displays the responses in list format. The Table tab provides an table format with the option to export it to Excel.
