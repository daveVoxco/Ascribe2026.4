# Remove Last Codes Applied

Remove Last Codes Applied is a right-click option in the Response Pane, activated only when a code has been applied to a response. (If no codes have been applied in the session, the option is available but will not be active.)

The action will remove the last code applied to a response. The dialog also gives the option to remove all codes from the responses.

When you right-click a code and select Remove Last Codes Applied, a confirmation dialog displays. The number in parentheses at the top of the dialog indicates how many responses are affected. The verbatim and applied code are also listed.

Click OK to remove the code(s) or click Cancel to discontinue the process.
