# Code Multiple Responses

There are several ways to select and apply codes in the Multiple Responses Coding Mode.

* Select any number of responses and click on a code (or multiple codes). We no longer have to drag and drop codes to apply them. We can select multiple responses and then click on the appropriate codes.
* Drag a code to a response.  Use this mode when you do not want to select responses. It works to code one responses at a time. Drag and drop does not respect highlighted responses. It’s a convenient way to apply a single code to a single response. This method comes in handy when you have selected multiple responses but need to apply a single code to a couple of those responses without it applying to all. It’s a “clean-up” tool when mass coding.
* Select any number of codes and hit the Apply Code target for individual responses. This method requires a Responses Settings configuration. The option to display the “Apply Selected Codes Button” must be toggled-on for this method to work.
* Click the regular expression hyperlink. See [Regular Expressions](codebooks/regular-expressions.md) for more information.
* Right click on an applied code and choose “Select Code in Codebook”, then hit the Apply Code target.
* If you select "Drag Response to Copy Coding" in Responses Settings, you can copy the codes applied from one response to another.
* You can also drag one applied code from a response to another response.
* To select a response, click the response. To select multiple responses, use Shift/Click.

When a code is applied to a response, and until the newly applied code is displayed, the response is highlighted orange. This gives you a visual indication of response with a pending coding operation. Similarly, codes removed from a response are highlighted red until the code is removed from the display. If you do not want to see these highlights, you can turn them off with the [Pending Operation Highlights](responses-settings.md#minitocbookmark5) option on the Responses Settings/Appearance tab.
