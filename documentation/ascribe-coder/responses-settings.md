# Responses Settings

![](https://static.goascribe.com/Help/responses_settings_icon_020521.gif)

The Settings dialog controls how the responses and optional information are displayed. The dialog has these tabs: [Responses](responses-settings.md#minitocbookmark2), [Related Responses](responses-settings.md#minitocbookmark3), [Applied Codes](responses-settings.md#minitocbookmark4), [Appearance](responses-settings.md#minitocbookmark5), and [When Starting](responses-settings.md#when-starting).
