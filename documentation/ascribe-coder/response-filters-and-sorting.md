# Response Filters and Sorting

![](https://static.goascribe.com/Help/filters_and_sorting_icon_071514.gif)

Click the Filters and Sorting icon to display the dialog which allows you to alter the display of responses with [filters](response-filters-and-sorting.md#minitocbookmark2) and [sorting](response-filters-and-sorting.md#sorting) options. Note that the icon may be hidden through the [Tools setting](responses-settings.md#minitocbookmark5) on the Appearance tab of Responses Settings. You can also access the Filters and Sorting dialog through the navigation menu option of Tools.

## Sort by Related Responses <a href="#minitocbookmark4" id="minitocbookmark4"></a>

The option to sort by first related response has these rules:

* When a question has more than one related question, the first question in the Related Questions pane is the question used by the sort.
* Numbers are sorted first and then alphabetically by text.
* If respondents do not have related responses, those items are sorted last.
