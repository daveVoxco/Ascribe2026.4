# Responses Right-Click Menu

The responses right-click menu has the following options:

<table><thead><tr><th width="265.99993896484375" valign="top">Option</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top"><strong>When responses are not selected, these options are available:</strong></td><td valign="top"></td></tr><tr><td valign="top">Select</td><td valign="top"><p>Has these options:</p><ul><li><strong>All –</strong> Selects and highlights all of the responses displayed in the Response pane</li><li><strong>All same –</strong> Selects and highlights all responses displayed in the Response pane that are exact textual match</li><li><strong>All codes in this response –</strong> Selects and highlights all of the codes applied to the response you clicked</li></ul></td></tr><tr><td valign="top">Hide</td><td valign="top">Allows user to hide the response from the rest of responses displayed in the Response pane. Hidden responses can be restored by searching for the response or using the Search Again icon.</td></tr><tr><td valign="top"><strong>When responses are or are not selected, these options are also available:</strong></td><td valign="top"></td></tr><tr><td valign="top">Edit</td><td valign="top"><p>This option displays the <a href="edit-response.md">Edit Response dialog</a>. Users can edit the Verbatim*, Translation, Transcription and Notes fields. Users can also quality review coding, verbatims, translations, transcriptions and notes.</p><p><strong>*Note:</strong> The option <a href="../site-administration/site-configuration.md">Allow Verbatim Editing in Ascribe Coder</a> must be enabled on the Account Options page in order to edit the Verbatim field.</p></td></tr><tr><td valign="top">All Responses For This Respondent</td><td valign="top">Displays a pop-up box with all of the responses within the study for a single respondent.</td></tr><tr><td valign="top">Translate</td><td valign="top">Displays the Translate dialog and allows the user to translate the response. See <a href="translate-response.md">Translate Response</a> for more information.</td></tr><tr><td valign="top">Reclassify</td><td valign="top">Displays the Reclassify dialog and allows user to reclassify the response. See <a href="reclassify-response.md">Reclassify Response</a> for more information.</td></tr><tr><td valign="top">Remove Last Codes Applied</td><td valign="top"><p>Remove Last Codes Applied is activated only when a code has been applied to a response. (If no codes have been applied in the session, the option is available but will not be active.)</p><p>The action removes the last code applied to a response. If <a href="responses-settings.md">Code Duplicates</a> is selected in the Responses Settings dialog, the code is removed from the duplicate verbatim depending on the setting. See <a href="remove-last-codes-applied.md">Remove Last Codes Applied</a> for more information.</p></td></tr><tr><td valign="top">Code Single Response</td><td valign="top">Changes to Single Response Coding mode and displays the response. This option is most useful when reviewing responses coded by segments. When a response is in Single Response Coding mode, you can change/add segments and codes. For more information, see <a href="code-single-responses.md#minitocbookmark4">Code Segments</a>.</td></tr><tr><td valign="top">Create Sample</td><td valign="top">Allows user to create a sample from the displayed responses. For more information, see <a href="create-a-sample.md">Create a Sample</a>.</td></tr><tr><td valign="top"><strong>When responses are selected, these options are available:</strong></td><td valign="top"></td></tr><tr><td valign="top">Select</td><td valign="top"><p>Has these options:</p><ul><li><strong>All –</strong> Selects and highlights all of the responses displayed in the Response pane</li><li><strong>All same –</strong> Selects and highlights all responses displayed in the Response pane that are exact textual match</li><li><strong>All codes in selected responses -</strong> Selects and highlights all of the codes applied to the selected response(s)</li><li><strong>All codes in this response –</strong> Selects and highlights all of the codes applied to the response you clicked</li></ul></td></tr><tr><td valign="top">Deselect</td><td valign="top"><p>Has these options:</p><ul><li><strong>All –</strong> Deselects and unhighlights all of the responses displayed in the Response pane</li><li><strong>All same –</strong> Deselects and unhighlights all responses displayed in the Response pane that are exact textual match</li></ul></td></tr><tr><td valign="top">Previous Selected</td><td valign="top">Allows user to find the next selected response <strong>above</strong> the current one. <strong>Screen scrolls up</strong> to the first selected response above the current one; the highlight of that response will flash yellow to bring attention to the response.</td></tr><tr><td valign="top">Next Selected</td><td valign="top">Allows user to find the next selected response <strong>below</strong> the current one. <strong>Screen scrolls down</strong> to the first selected response below the current one; the highlight of that response will flash yellow to bring attention to the response.</td></tr><tr><td valign="top">Hide</td><td valign="top">Allows user to hide a response or selected responses from the rest of responses displayed in the Response pane. Hidden responses can be restored by searching for the response or using the Search Again icon.</td></tr><tr><td valign="top">Set Selected Responses</td><td valign="top">Sets the review status for coding quality, verbatim, translation, transcription, or notes.</td></tr><tr><td valign="top">Clear Selected Responses</td><td valign="top">Clears the review status for coding quality, verbatim, translation, transcription, or notes.</td></tr><tr><td valign="top"><strong>When part of a response is selected, this option is available:</strong></td><td valign="top"></td></tr><tr><td valign="top">Add Selection To Notes</td><td valign="top">Allows user to add part of a response to the Notes field. To use, highlight a piece of a response and right-click and select this option. To see the note, toggle on the <a href="responses-settings.md">Notes field in the Responses Settings dialog</a>.</td></tr></tbody></table>
