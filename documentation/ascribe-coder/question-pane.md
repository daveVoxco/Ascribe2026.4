# Question Pane

The Question Pane lists the questions which are being coded. See [Panes](./#minitocbookmark4) for more information about opening and closing the pane.

The following information is listed in the pane: Study ID, hyperlinked Question Properties dialog, Question ID, Question Label, Question Type, and Question Text.
