# Sources

![](https://static.goascribe.com/Help/sources_icon_071514.gif)

Click the Sources icon to display the Source dialog, where you can pick either the questions you want to code or if available, samples (or subsets) of the data. Note that the Sources icon may be hidden through the [Tools setting](responses-settings.md#minitocbookmark5) on the Appearance tab of Responses Settings. You can also access the Sources dialog through the navigation menu option of Tools.

The dialog has two tabs: [Questions](sources.md#minitocbookmark2) and [Samples](sources.md#minitocbookmark4). For more information about samples, see [Create a Sample](create-a-sample.md).

![](https://static.goascribe.com/Help/Sources_dialog.gif)

## Select Questions <a href="#minitocbookmark2" id="minitocbookmark2"></a>

Use the Questions tab to select additional questions to code. The questions must share the codebook and must have data to appear in the list of questions.

<table><thead><tr><th width="290.33331298828125" valign="top">Column</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top">Questions Sharing This Codebook</td><td valign="top">Displays a list of all questions that share the codebook, including questions from other studies. The questions are in order by study.</td></tr><tr><td valign="top">Selected Questions</td><td valign="top">Displays a list of questions that were selected for coding. Use the forward and backward arrow buttons to move questions from one pane to another.</td></tr></tbody></table>

## Add Shared Question <a href="#minitocbookmark3" id="minitocbookmark3"></a>

To add a question to the Selected Questions pane, click a question and then click the forward arrow button:

![](https://static.goascribe.com/Help/Questions_dialog_02.gif)

## Remove Shared Question <a href="#minitocbookmark4" id="minitocbookmark4"></a>

To remove a question from the Selected Questions pane, click a question and then click the backward arrow button:

![](https://static.goascribe.com/Help/Questions_dialog_03.gif)

## Always Start with Shared Questions from Current Study <a href="#minitocbookmark5" id="minitocbookmark5"></a>

If you always want the shared questions in the current study to be included, use the [Include questions from current study sharing codebook option](responses-settings.md#when-starting) in the Responses Setting dialog. Note: only the shared codebooks within the current study will automatically be displayed every time. If you want to see shared questions from other studies, use the Questions dialog to select those.

## Samples Tab <a href="#minitocbookmark6" id="minitocbookmark6"></a>

To display a sample, click the Samples tab and then click the radio button next to a sample. To change back to a question, click the Questions tab and select a question or questions.

Note that coding a sample will only affect items within that sample; for example, Code Duplicates will only code responses in the sample and not in the rest of the question or questions.

![](https://static.goascribe.com/Help/Sample_tab.gif)

When you are working with a sample, the Questions pane at the bottom of the screen will display the sample ID and the questions from which the sample was taken.
