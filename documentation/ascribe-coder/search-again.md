# Search Again

The Search Again option repeats the last search that you did. It uses the settings in the Search Responses dialog. The Search Again icon is on the Responses Pane Toolbar:

![](https://static.goascribe.com/Help/search_again_icon_04_071514.gif)

The Search Again option can act as a screen refresh. It is meant to be a convenient way to search for responses without opening the Search Responses dialog.

## Paging of Large Response Sets

To enhance performance and improve productivity when working with large numbers of responses, Ascribe Coder supports paging of responses. Ascribe Coder will now display a maximum of 1000 responses, or a smaller number if specified in the Search dialog. When there are more responses meeting the search criteria than the selected maximum, the Search Again button will display the current page, and the number of additional pages to view. Click the Search Again button to display the next set of responses, or Ctrl-click to return to the first page of responses.

![](https://static.goascribe.com/Help/search_again_with_paging_071514.gif)
