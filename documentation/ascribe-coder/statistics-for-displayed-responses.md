# Statistics for Displayed Responses

Display of the messages is controlled through the [Tools settings](responses-settings.md#minitocbookmark5) in the Appearance tab of Responses Settings. If the display is on, you receive messages in the Responses toolbar about the responses returned from a search. Here is an example:

![](https://static.goascribe.com/Help/Responses_displayed_and_messages.gif)

If you hover over any of the messages, a tooltip displays more detailed information:

![](https://static.goascribe.com/Help/Hover_help_for_messages.gif)

Here is an explanation of the messages:
