# Edit Response

Edit Response allows you to edit the fields associated with the response. Note: In order to edit the verbatim, the account option of [Allow Verbatim Editing in Ascribe Coder](../site-administration/site-configuration.md) must be selected. &#x20;

Here is an example of the Edit Response dialog:

![](https://static.goascribe.com/Help/Edit_Response_dialog.gif)

The study ID, question ID, and respondent ID display at the top of the dialog. These fields cannot be changed.

Here are the fields that can be changed:
