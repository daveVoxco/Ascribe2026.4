# Audio Playback

Ascribe supports coding from sound files. Coding from sound files is designed for working with voice files from IVR systems. The user can code sound files in Ascribe Coder by clicking the blue audio link to display the Audio Playback window to listen to the sound file on the audio player.

Here is an example of the Audio Playback window:

![](https://static.goascribe.com/Help/audio_playback.gif)
