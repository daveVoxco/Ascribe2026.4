# Search Codebook

![](https://static.goascribe.com/Help/search_codebook_icon_071514.gif)

When a codebook is not empty, you can use the Search Codebook option to find and/or replace code descriptions. (If the codebook is empty, the [Search for Codebook](search-for-codebook.md) dialog displays.)

Here is the Search Codebook dialog:

![](https://static.goascribe.com/Help/Search_codebook_dialog_dec4.gif)

The small arrow at the top of the dialog allows the user to hide the Options of the dialog; this action makes the dialog smaller and take up less room on the screen. Click the arrow to toggle the options on and off.

Here is the Search Codebook dialog with the options hidden:

![](https://static.goascribe.com/Help/Search_Codebook_dialog_options_hidden.gif)

### Insert Code When Using Search Codebook

When a partial codebook is displayed, you can still add codes. Right-click a code and select Insert Code. The code will be inserted below the code you right-clicked.

### Replace in Description

Here is an example of how to use the Replace in Description tab:

While coding a question, a user added new codes and put asterisks in front of the codes to make them more visible. Now the asterisks need to be removed. Enter an asterisk in the Find text box and leave the Replace text box blank, as shown below.

![](https://static.goascribe.com/Help/replace_asterisks_071514.gif)

After pressing Go, a confirmation dialog displays. If there is an entry that you do not want changed, click the checkbox to toggle it off. Click OK to continue or Cancel to stop the process.

![](https://static.goascribe.com/Help/replace_in_description_dialog_071514.gif)
