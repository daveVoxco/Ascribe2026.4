# Net Right-Click Menu

The right-click menus found in the Codebook pane depend on whether the codebook is locked or unlocked.

### Net Right-Click Menu (Locked Codebook) <a href="#minitocbookmark2" id="minitocbookmark2"></a>

When the codebook is locked, the Net right-click menu has the following options:

<table><thead><tr><th width="233" valign="top">Option</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top"><strong>When you right-click a net &#x26; no codes are selected, these options are available:</strong></td><td valign="top"></td></tr><tr><td valign="top">Code Properties</td><td valign="top">Displays the code properties dialog. For more information, see <a href="edit-code.md">Edit Code</a>.</td></tr><tr><td valign="top">Toggle Focus</td><td valign="top">Allows users to edit the codebook using the keyboard. The focus moves around in response to the up/down arrow keys. For more information, see <a href="use-keyboard-to-edit-codebook.md">Use Keyboard to Edit Codebook</a>.</td></tr><tr><td valign="top">Information</td><td valign="top"><p>Displays the Code Information dialog which lists input ID, output ID, code ID, description, regular expression, hover help, and long help.</p><p>The Where Used section displays the study ID, question ID, number of codes applied, percentage of all responses, percentage of responses coded, and percentage of study respondents.</p></td></tr><tr><td valign="top">Show Last Child</td><td valign="top"><p>Codebook scrolls to the last child of the net; the last child will be either the last subnet of the net (if subnets are present) or the last code of the net.</p><p>You can also use the keyboard shortcut of shift/click to move to the last child of the net.</p></td></tr><tr><td valign="top">Select Siblings</td><td valign="top"><p>With nets, siblings are codes or nets that are at the same level of the net. Has these options:</p><ul><li><strong>Codes –</strong> Selects and highlights all of the net's sibling codes</li><li><strong>Used codes –</strong> Selects and highlights all of the net's sibling codes which have been applied to responses</li><li><strong>Unused codes -</strong> Selects and highlights all of the net's sibling codes which have not been applied to any responses</li><li><strong>To selected above -</strong> Selects and highlights siblings above the net</li><li><strong>To selected below -</strong> Selects and highlights siblings below the net</li></ul></td></tr><tr><td valign="top">Select Descendants</td><td valign="top"><p>With nets, descendants are the children codes of the net; this includes children codes found in subnets of the net.</p><p>Has these options:</p><ul><li><strong>Codes –</strong> Selects and highlights all of the codes in the net</li><li><strong>Used codes –</strong> Selects and highlights all codes in the net that have been applied to responses</li><li><strong>Unused codes -</strong> Selects and highlights all of the codes in the net that have not been applied to any responses</li></ul></td></tr><tr><td valign="top">Insert Code</td><td valign="top"><p>Opens the <a href="edit-code.md">Code Properties dialog</a>, to add a new code.</p><p>Has these options:</p><ul><li><strong>Below –</strong> Inserts code below the last code of the net; the newly added code is not part of the net</li><li><strong>Into –</strong> Inserts code into the net, at the top of the net; the newly added code is part of the net</li></ul></td></tr><tr><td valign="top">Add Code Based On Selected Responses</td><td valign="top"><p>Adds a code in the net, directly below the net node, based on selected responses.</p><p>If one response is selected, the code description is populated with the response. If multiple responses are selected, the code description is blank.</p><p>The regular expression field is populated with the selected response or responses if:</p><ul><li>the responses are 50 characters or less.</li><li>the responses do not contain regular expression operators.</li><li>the responses do not contain multiple sentences separated by punctuation marks.</li></ul><p>After you click OK, the newly created code is applied to the selected responses.</p></td></tr><tr><td valign="top"><strong>When you right-click a net &#x26; nets or codes are selected, these options are also available:</strong></td><td valign="top"></td></tr><tr><td valign="top">Deselect All</td><td valign="top">Deselects and unhighlights any code or net that is selected.</td></tr><tr><td valign="top">Deselect Siblings</td><td valign="top"><p>With nets, siblings are codes or nets that are at the same level of the net. Has these options:</p><ul><li><strong>Codes –</strong> Deselects and unhighlights all of the net's sibling codes</li><li><strong>Used codes –</strong> Deselects and unhighlights all of the net's sibling codes which have been applied to responses</li><li><strong>Unused codes -</strong> Deselects and unhighlights all of the net's sibling codes which have not been applied to any responses</li><li><strong>Empty nets -</strong> Deselects and unhighlights nets that have no children (no codes)</li><li><strong>To deselected above -</strong> Deselects and unhighlights siblings above the net</li><li><strong>To deselected below -</strong> Deselects and unhighlights siblings below the net</li></ul></td></tr><tr><td valign="top">Deselect Descendants</td><td valign="top"><p>With nets, descendants are the children codes of the net; this includes children codes found in subnets of the net.</p><p>Has these options:</p><ul><li><strong>Codes –</strong> Deselects and unhighlights all of the codes in the net</li><li><strong>Used codes –</strong> Deselects and unhighlights all codes in the net that have been applied to responses</li><li><strong>Unused codes -</strong> Deselects and unhighlights all of the codes in the net that have not been applied to any responses</li><li><strong>Empty nets -</strong> Deselects and unhighlights any subnets that have no children (no codes)</li></ul></td></tr></tbody></table>
