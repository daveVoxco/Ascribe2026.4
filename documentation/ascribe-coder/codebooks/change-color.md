# Change Color

![](https://static.goascribe.com/Help/Change_color_icon_02_071614.gif)

Use this option to change the color of selected codes/nets. The codebook must be unlocked and codes/nets must be selected. Select desired codes/nets, and then click the Change Color icon. Choose desired color from the color selections, and then press the Close button.
