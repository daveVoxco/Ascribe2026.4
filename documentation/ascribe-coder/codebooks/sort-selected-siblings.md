# Sort Selected Siblings

The Sort Selected Siblings option is a right-click menu item available when the codebook is unlocked and some codes are selected.&#x20;

Use this sort option to sort sibling codes within one net or to sort unnetted sibling codes. If you have multiple codes selected in more than one net, the sort works where you right-clicked and selected the sort option.

If non-consecutive codes are selected, the sort will not displace the non-selected codes.

When sorting unnetted codes, any of those that are selected will be sorted, no matter where they are in the codebook.

Here are the sort codebook options:

<table><thead><tr><th width="246" valign="top">Option</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top"><strong>Sort By</strong></td><td valign="top"> </td></tr><tr><td valign="top">Input ID</td><td valign="top">Puts the codes in numerical order by the input ID.</td></tr><tr><td valign="top">Output ID</td><td valign="top">Puts the codes in numerical order by the output ID.</td></tr><tr><td valign="top">Description</td><td valign="top">Puts the codes in alphabetical order by the code description.</td></tr><tr><td valign="top">Reverse The Sort</td><td valign="top">Reverses the order of the Sort By option.</td></tr></tbody></table>
