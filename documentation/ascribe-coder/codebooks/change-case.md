# Change Case

![](https://static.goascribe.com/Help/Change_case_icon_03_071614.gif)

In order to change the text casing of codes/nets within the codebook, you must first unlock the codebook and then select the codes/nets you would like to change the case. After the codes/nets have been selected, click the Change Case icon and complete the criteria for changing the case.

<table><thead><tr><th width="217.99993896484375" valign="top">Option</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top">Uppercase</td><td valign="top">Changes text to all uppercase.</td></tr><tr><td valign="top">Lowercase</td><td valign="top">Changes text to all lowercase.</td></tr><tr><td valign="top">First Letter Capital</td><td valign="top">Changes only the first word to start with a capital letter. (If a word has a special character such as * in front of it, the word itself will not be capitalized.)</td></tr><tr><td valign="top">Title Case</td><td valign="top">Changes each word to start with a capital letter.</td></tr></tbody></table>
