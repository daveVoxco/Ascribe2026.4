# Codebook Information

The Codebook information is available from the Codebook Pane. Right-click at the top of the codebook, then select “Information” and a dialog displays. Click Close when you are finished.

The Codebook Information dialog displays the number of nets, empty nets, codes, and unused codes. It also displays the study ID and question ID.

The shortcut of Ctrl/Shift/Click on the codebook node also opens the codebook information dialog.
