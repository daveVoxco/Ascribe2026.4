# Load Large Codebooks

If the codebook contains more than 1000 codes and nets, Ascribe Coder will ask you whether you want to load the codebook. If you load the codebook, the entire codebook is displayed in Ascribe Coder. If you do not load the codebook, only the codebook node displayed in the right pane of Ascribe Coder. The codes and nets are not displayed.

When the codebook is large, loading the codebook can be time consuming. It will also make all operations in the browser slower, because of the large size of the document the browser is displaying. By not loading the codebook you can dramatically improve performance of the browser.

You can partially load a codebook in the Summary dialog. Select the checkboxes for the nets you want to load, then click the Load Selected Nets button. (Alternatively, you can use the [Search Codebook dialog](search-codebook.md) to load a partial code. Select the Load radio button, then perform your search. The matching nets and codes are loaded.)

If you have partially loaded a codebook and wish to load the entire codebook, either click the Load Codebook button in the Summary dialog, or select the Load Entire Codebook option in the Search Codebook dialog

You can add codes to the codebook when it is not loaded by choosing Insert code menu item on the codebook itself. Codes added in this way are placed at the top of the codebook. You can delete codes by searching for the code to delete, then deleting it.

When the codebook is not loaded, you can still export the codebook as usual. In this way, you can have a document showing the entire codebook for your reference without the need to load the codebook.
