# Sort Codebook

The Sort Codebook option is a right-click menu item available when the codebook is unlocked.

Use the Sort option to:

* Sort codes in an individual net
* Sort the nets and unnetted codes
* Sort unnetted codes (a list of codes that have no nets.)

The sort does not sort all netted codes at one time. You have to do each net separately. &#x20;

If you want to sort the codes in an individual net, select the net, right-click the net, and select Sort.

If you want to sort all nets and unnetted codes, right-click the codebook node and select Sort.

If you want to sort a list of codes that have no nets, right-click the codebook node and select Sort.
