# Codebook Node Right-Click Menu

The right-click menus found in the Codebook pane depend on whether the codebook is locked or unlocked.

### Codebook Node Right-Click Menu (Locked Codebook) <a href="#minitocbookmark2" id="minitocbookmark2"></a>

When the codebook is locked, the Codebook Node right-click menu has the following options:

<table><thead><tr><th valign="top">Option</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top"><strong>When you right-click the Codebook Node, these options are available:</strong></td><td valign="top"></td></tr><tr><td valign="top">Codebook Properties</td><td valign="top">The Codebook Properties dialog displays. See <a href="edit-codebook-properties.md">Edit Codebook</a> for more information.</td></tr><tr><td valign="top">Information</td><td valign="top">The Codebook Information dialog displays. This dialog lists the number of nets, empty nets, codes, and unused codes.</td></tr><tr><td valign="top">Check Spelling</td><td valign="top">Opens the Check Spelling dialog. See <a href="check-spelling.md">Check Spelling</a> for more information.</td></tr><tr><td valign="top">Show Last Child</td><td valign="top"><p>Codebook scrolls to the last child of the codebook; the last child will be either an unnetted code or the last net of the codebook.</p><p>You can also use the keyboard shortcut of shift/click to move to the last child of the codebook.</p></td></tr><tr><td valign="top">Select Descendants</td><td valign="top"><p>Has these options:</p><ul><li><strong>Codes</strong> – Selects and highlights all of the codes in the codebook</li><li><strong>Used codes</strong> – Selects and highlights all codes that have been applied to responses</li><li><strong>Unused codes</strong> - Selects and highlights all of the codes that have not been applied to any responses</li></ul></td></tr><tr><td valign="top">Insert Code</td><td valign="top">Opens the <a href="edit-code.md">Code Properties dialog</a>, to add a new code at the top of the codebook.</td></tr><tr><td valign="top">Add Code Based On Selected Responses</td><td valign="top"><p>Adds a code under the codebook node based on selected responses.</p><p>If one response is selected, the code description is populated with the response. ### Codebook Node Right-Click Menu (Unlocked Codebook) <a href="#minitocbookmark3" id="minitocbookmark3"></a>

When the codebook is unlocked, the Codebook Node right-click menu has the following options:

| Option                                                                                             | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| -------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **When you right-click the Codebook Node, these options are available:**                           |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Codebook Properties                                                                                | The Codebook Properties dialog displays. See [Edit Codebook](edit-codebook-properties.md) for more information.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Information                                                                                        | The Codebook Information dialog displays. This dialog lists the number of nets, empty nets, codes, and unused codes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Check Spelling                                                                                     | Opens the Check Spelling dialog. See [Check Spelling](check-spelling.md) for more information.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Show Last Child                                                                                    | <p>Codebook scrolls to the last child of the codebook; the last child will be either an unnetted code or the last net of the codebook.</p><p>You can also use the keyboard shortcut of shift/click to move to the last child of the codebook.</p>                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Select Descendants                                                                                 | <p>Has these options:</p><ul><li>All - Selects and highlights all codes and nets in the codebook</li><li>Codes – Selects and highlights all of the codes in the codebook</li><li>Used codes – Selects and highlights all codes that have been applied to responses</li><li>Unused codes - Selects and highlights all of the codes that have not been applied to any responses</li><li>Empty nets - Selects and highlights any net that has no children</li><li>Unused nets - Selects and highlights any net whose codes have not be used</li></ul>                                                                                                                                         |
| Insert Code                                                                                        | Opens the [Code Properties dialog](edit-code.md), to add a new code at the top of the codebook.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Sort                                                                                               | See [Sort Codebook](sort-codebook.md) for more information.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Renumber                                                                                           | When renumbering using this command, the entire codebook is renumbered. This is particularly useful when working with a large codebook which has not been loaded into the browser. Using this command, you can renumber the codebook without the need to load it.                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Delete                                                                                             | If the codebook is unused, you can delete it with this option. If any code has been used, this option is not available.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Copy                                                                                               | Copies the current codebook for use in the [Paste Codes](copy-and-paste-codebooks-from-excel-or-word.md) dialog.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Paste                                                                                              | Opens the [Paste Codes](copy-and-paste-codebooks-from-excel-or-word.md) dialog which allows you to copy and paste codes into Ascribe.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Import Taxonomy                                                                                    | Option available if account has Inspector license and user has Inspector privilege. Copies a taxonomy's groups into the codebook as codes, and expressions are created from the synonyms.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Add Code Based On Selected Responses                                                               | <p>Adds a code under the codebook node based on selected responses.</p><p>If one response is selected, the code description is populated with the response. If multiple responses are selected, the code description is blank.</p><p>The regular expression field is populated with the selected response or responses if:</p><ul><li>the responses are 50 characters or less.</li><li>the responses do not contain regular expression operators</li><li>the responses do not contain multiple sentences separated by punctuation marks.</li></ul><p>After you click OK, the newly created code is applied to the selected responses.</p>                                                  |
| **When you right-click the Codebook Node & codes are selected, these options are also available:** |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Deselect All                                                                                       | Deselects and unhighlights any code or net that is selected.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Deselect Descendants                                                                               | <p>Has these options:</p><ul><li>All - Deselects and unhighlights all codes and nets in the codebook</li><li>Codes – Deselects and unhighlights all of the codes in the codebook</li><li>Used codes – Deselects and unhighlights all codes that have been applied to responses</li><li>Unused codes - Deselects and unhighlights all of the codes that have not been applied to any responses</li><li>Empty nets - Deselects and unhighlights any nets that have no children (no codes)</li></ul>                                                                                                                                                                                          |
| Move Selection                                                                                     | <p>Moves the selection either into or below the currently selected location.</p><p>First, select the code/codes/net/nets that you want to move.</p><p>Then, right-click the code or net where you want to move the selection and click Move Selection.</p><p>This option is useful for moving codes in large codebooks.</p><p>In the example below, Code 209 is selected. We right-clicked Code 208 and are using Move Selection>Below to move Code 209 below Code 208. (Note that the Move Handle does not have to be displayed in order to use Move Selection.)</p><p><img src="https://static.goascribe.com/Help/example_of_move_selection_071514.gif" alt="" data-size="original"></p> |
| Copy Selected Codes                                                                                | Copies selected codes for use in the [Paste Codes](copy-and-paste-codebooks-from-excel-or-word.md) dialog.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| [Combine Selected Codes](combine-selected-codes.md)                                                | Combines selected codes into the code you right-clicked.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
