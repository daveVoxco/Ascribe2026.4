# Copy and Paste Codebooks from Excel or Word

Ascribe allows the user to copy and paste codes into the codebook from a text document or an Excel spreadsheet.

1.  Before you copy and paste the codes, prepare the source document so that the outputID of the code appears to the left of the description of the code, separated by a tab (or in a different cell in Excel). You can also indent the codes with tabs or empty cells to indicate the net level.

    **An example of a properly formatted codebook in Excel:**

    ![](https://static.goascribe.com/Help/07_-_Codebooks_julie_files/image015.jpg)

    **An example of a properly formatted codebook in Word (with all characters displayed):**

    <figure><img src="https://static.goascribe.com/Help/07_-_Codebooks_julie_files/image017.jpg" alt=""><figcaption></figcaption></figure>
2. To copy the document, select the desired portion of the document and select **Copy** from the Edit menu.
3. Navigate to Ascribe Coder.
4. To paste the codes into an empty codebook, unlock the codebook, right-click the codebook node, and select **Paste**.
5. Paste copied text into the text box on the left.
6. Optional: Select Do Not Parse Numbers for InputIDs if you want the Input ID and Output ID to be blank. This option is especially useful if the code descriptions start with numbers or contain numbers.
7. Click Show to view codes prior to pasting them into codebook.
8. Click Paste Into to paste codes into codebook and click Close when you are finished.
9. To paste the codes into an existing codebook, right-click the net or code where you want to insert the copied codes. Select **Paste** and follow steps 5, 6, 7 and 8.
