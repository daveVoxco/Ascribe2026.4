# Renumber Codes

![](https://static.goascribe.com/Help/Renumber_Icon_03_071614.gif)

In order to renumber the codebook, you must first unlock the codebook and then select the codes/nets you would like to renumber. Only codes/nets that are selected will be renumbered.

After the codes/nets have been selected, click on the Renumber icon and complete the criteria for renumbering the codebook.

Here are the fields in the Renumber dialog:

When renumbering multiple fields (input, output, code ID) with the Blanks Only option set, the renumbering takes place if ANY of the fields are blank. In that case, ALL of the fields are set to the new value.</p></td></tr><tr><td valign="top">Start</td><td valign="top"><strong>Enter a value in this field. The first code or net will start with this number.</strong></td></tr><tr><td valign="top">Increment</td><td valign="top"><p>The codes are increased by the number in this field. For example, if the start code value is 1, and the spread between codes is 10, the values assigned will be 1, 11, 21, 31, 41, etc.</p><p> </p><p>The default value for this field is set in the Codebook Properties dialog.</p></td></tr><tr><td valign="top">Digits</td><td valign="top"><strong>This field defines the number of digits in the code values and whether leading zeros are used. A blank or zero means the value will not be given leading zeros. A number greater than zero means the value will be given leading zeros. The maximum value is 20.</strong></td></tr><tr><td valign="top">Ignore</td><td valign="top"><p>You can prevent codes from being renumbered by entering the number here.
