# Code Information

The Code Information dialog is available from the Codebook Pane. Right-click on a code, then select Information, and a dialog displays. Click Close when you are finished.

The Code Information dialog displays the input ID, output ID, code ID, description, regular expression, hover help, and long help (when there is data in the fields.)

The Where Used section displays the study ID, question ID, number of codes applied, percentage of all responses, percentage of responses coded, and percentage of study respondents.
