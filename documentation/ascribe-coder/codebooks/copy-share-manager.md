# Copy/Share Manager

_Navigate: Studies/Right-click a study/Select Copy/Share Manager_\
&#xNAN;_&#x53;tudies/Right-click a study/Select Questions/Right-click a question/Select Copy/Share>Copy/Share Manager_

For general information about copying or sharing codebooks, see [Share and Copy Codebooks](share-and-copy-codebooks.md).

As the name implies, the Copy/Share Manager allows you to copy or share the codebooks of a study to other questions. It allows you to share multiple questions in a study at one time. It also allows you to find any codebook on your site and to copy or share any of the codebooks with the questions in your study.

The Copy/Share Manager also has a section for [Related Questions](copy-share-manager.md#related-questions). Related questions allow coders to see the response to another question while in Ascribe Coder. For example, you have an open-ended response, and you would like to see the closed-ended response that relates to this question. See [Related Questions](copy-share-manager.md#related-questions) for more info.

## How to Copy and Share with the Copy/Share Manager

Choose the source of the codebook in the [Choose From pane](copy-share-manager.md#choose-from-pane).

Select the source question or codebook in the [Source pane](copy-share-manager.md#source-pane).

Select the target question or codebook in the [Target pane](copy-share-manager.md#target-pane). Because the Copy/Share Manager allows you to copy/share multiple questions or codebooks, you can select as many questions or codebooks in the Target pane as you would like.

Click the <img src="../../../.gitbook/assets/image (270).png" alt="" data-size="line"> Copy icon or the <img src="../../../.gitbook/assets/image (271).png" alt="" data-size="line"> Share icon.

Note that when you use the copy option, you could be unsharing a previously shared question. But, the Copy/Share Manager lets you re-establish the share if needed. It can save you time if you are aware of the shared relationships between questions before you do anything. The double-arrow icon can help remind you of these relationships.

Note that using the Empty Codebook option also affects the shared relationships of questions. You can create a share between questions if you select Empty Codebook and multiple questions and choose Share. Also, you will unshare questions if you use the Copy option.

## View Codebooks

To view a codebook, click the number in the Codes column. A dialog displays with the codebook. Click the pin button (<img src="https://static.goascribe.com/Help/pin_icon.png" alt="" data-size="line">) at the right top of the dialog to keep the codebook displayed. Click Close to remove it from the screen. You can have more than one codebook displayed at a time.

## Unshare Questions with the Copy/Share Manager

To unshare a question with the Copy/Share Manager, click the number of shared questions (here is an example: <img src="https://static.goascribe.com/Help/Number_of_shared_questions.gif" alt="" data-size="line">) to display the shared questions. Use the Unshare option of the dialog to unshare the questions.

You can also copy or share an empty codebook to unshare a codebook or wipe out an unused codebook in the Target pane.

These pages also have ways to unshare questions:

* Questions Page
* Questions Page/right-click menu option Copy/Share

## Related Questions

Related questions allow coders to see the response to another question while in Ascribe Coder. For example, you have an open-ended response, and you would like to see the closed-ended response that relates to this question.

To use the Related Questions option, click Set Question Relationships.

The Source pane displays the questions in the study. If some questions already have related questions, the Related pane displays the questions in the study. If there are no related questions, then the Related pane will be empty until you click a question in the Source pane.

To create a related question, click the appropriate question in the Source pane, then click a question in the Related pane, and then click the Link icon (<img src="https://static.goascribe.com/Help/Link_icon_for_Related_Questions.png" alt="" data-size="line">) in the toolbar. Once the questions are related, the question in the Source pane displays a forward arrow (<img src="https://static.goascribe.com/Help/Forward_arrow_for_Related_Questions.png" alt="" data-size="line">), and the question in the Related pane displays a backward arrow (<img src="https://static.goascribe.com/Help/Backward_arrow_for_Related_Questions.png" alt="" data-size="line">).

To remove relationships, click the question in the Source pane and the question in the Related pane, and then click the Unlink icon (<img src="https://static.goascribe.com/Help/Unlink_icon_for_Related_Questions.png" alt="" data-size="line">).

To use the related questions, select [Include Related Responses](../search-responses.md#minitocbookmark3) on the Find tab of Search Responses.

You can also [sort responses by the verbatim of the first related response](../response-filters-and-sorting.md#minitocbookmark4).
