# Edit Codebook Properties

The Codebook Properties dialog contains basic information about a codebook such as the codebook ID and description.

<table><thead><tr><th width="213.333251953125" valign="top">Field</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top">Codebook ID</td><td valign="top">This field is a unique, but optional, identifier for the codebook. If used, it allows you to access the codebook from other sources. The ID should be unique within all codebooks. An error will occur if you try to set this ID to a value that already exists for another codebook.</td></tr><tr><td valign="top">Description</td><td valign="top">This field provides a description of the codebook. You can use this field to provide information about the codebook, which may be useful particularly for shared codebooks.</td></tr><tr><td valign="top">Spread Between Codes</td><td valign="top"><p>This field determines how the default value for inputID and outputID are calculated. You may use any number greater than zero (up to 6 digits).</p><p> </p><p>When the <em>No duplicate outputID's</em> check box is cleared, the default value for a new code is determined by inspection of all of the siblings of the code. The default value will be the first whole multiple of <em>Spread between codes</em> greater than the outputID of all siblings. Only siblings with numeric outputIDs are considered.</p></td></tr><tr><td valign="top">No Duplicate OutputID's</td><td valign="top"><p>If this check box is selected, Ascribe will guarantee that the outputID of each code in the codebook is unique. When you assign a new value to the outputID of a code, Ascribe will change the outputID if necessary to ensure that it is unique within the codebook. If Ascribe changes the outputID, it will assign a large number. This is a visual indication that you need to correct the outputID.</p><p> </p><p>This check box is disabled if the codebook contains duplicate codes. To enable the check box, you must first ensure that all codes have unique outputIDs. Note that uniqueness applies to all codes in the codebook, including nets.</p></td></tr><tr><td valign="top"><a href="account-codebooks.md">Account Codebook</a></td><td valign="top">If this check box is selected, the codebook will be designated as an account codebook. The codebook must have an ID to use this option.</td></tr><tr><td valign="top">Master Codebook</td><td valign="top">If this check box is selected, the codebook is designated as a <a href="account-codebooks.md#minitocbookmark2">master codebook.</a></td></tr><tr><td valign="top">Notes</td><td valign="top">Use this optional field to enter additional information about the codebook.</td></tr><tr><td valign="top">Making Existing Codes Singleton</td><td valign="top"><p>This option allows you to set all existing codes in the codebook as <a href="edit-code.md">Singleton</a> or to clear the Singleton property from all codes.</p><p>Here are the options:</p><p><strong>Do not change -</strong> This option is the default and does not change any settings in the codebook.</p><p><strong>Set existing codes to Singleton -</strong> This option changes the code properties of all existing codes to Singleton. If codes are added after you use this option, they are not automatically set to Singleton (you would have to select Singleton when you add the codes) or use this option again. After you close the codebook properties dialog, the option reverts to Do not change.</p><p><strong>Clear Singleton from all codes -</strong> This option removes the Singleton property for all existing codes. After you close codebook properties dialog, the option reverts to Do not change.</p></td></tr></tbody></table>
