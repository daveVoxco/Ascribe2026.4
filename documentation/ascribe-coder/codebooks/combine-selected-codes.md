# Combine Selected Codes

Let’s suppose you have codes A, B, C, and D.  You want to merge A, B, and C into D, such that only code D remains.

Keep in mind that combining codes operates on the responses for the questions you are currently coding in Ascribe Coder. If you are coding across studies, you will affect those studies.

Do the following:

1. Unlock the codebook.
2. Select the codes that you want to merge into the combined code (codes A, B, and C).
3. Right-click the code you want to merge the selected codes into (code D).  This code can be selected or not.  That does not matter.
4. Select “Combine Selected Codes…”.  A confirmation dialog appears, showing the codes that will be merged into D.  The confirmation dialog lists for each code: the study and question where the code to be merged is found, the number of such codes that will be replaced by the merged code, and the number of such codes that will be deleted as a result of the merge.
5. Click OK to continue or Cancel to abort.
6. Once the merge is completed the Delete Codes dialog will appear, allowing you to delete the codes that were merged (A, B, C).  You can decide whether to delete them (OK) or leave them (Cancel).  If you leave them A, B, and C will still be there, but will not be applied to any responses. \*Note: if those codes have been used in another study that is not in your current Questions list, you cannot delete those codes.
7.  A word on the confirmation dialog counts.  The count of replacements is the number of times A, B, or C will be replaced by D in codes applied to responses.  But what if a response has A and D applied before the merge?  In that case A gets deleted from the response, because if we left it we would have D applied twice to that response.  So deletions happen when the result would have multiple of the same code applied.
