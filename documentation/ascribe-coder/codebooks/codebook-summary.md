# Codebook Summary

![](https://static.goascribe.com/Help/codebook_summary_icon_02_071514.gif)

This dialog displays a summary view of the nets in the codebook (if there are no nets, this dialog is not useful.) At the top of the summary appear numbers showing the available levels, or depth of nesting, of the nets. To change the level, click the number of the desired level. When you click a net in the summary, that net is expanded in the codebook and all other nets are collapsed. This action allows you to navigate quickly to a desired location within a large codebook.

You can partially load a codebook in the Summary dialog. Select the checkboxes for the nets you want to load, then click the Load Selected Nets button. (Alternatively, you can use the [Search Codebook dialog](search-codebook.md) to load a partial codebook. Select the Load radio button, then perform your search. The matching nets and codes are loaded.)

If you have partially loaded a codebook and wish to load the entire codebook, either click the Load Codebook button in the Summary dialog, or select the Load Entire Codebook option in the Search Codebook dialog.

You can also use CTRL/click on the codebook node to collapse and expand all nets.
