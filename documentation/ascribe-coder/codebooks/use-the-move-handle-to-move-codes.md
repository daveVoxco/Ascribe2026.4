# Use the Move Handle to Move Codes

When the codebook is **unlocked**, you can use the move handle to move codes around in the codebook. Using the move handle is best suited for moving 1 or 2 codes or nets. See [Move a Group of Codes](move-a-group-of-codes.md) if you have a large number of codes you would like to move or if you are working with a large codebook.

To display the move handle, click the Codebook Settings icon.

![](https://static.goascribe.com/Help/codebook_settings_icon_071514.gif)

Click the When Unlocked tab of the dialog and click Move Handle.

The move handle displays in an **unlocked** codebook like this:

![](https://static.goascribe.com/Help/Move_Handle_display.gif)

Use the move handle to drag a code or net to another location.
