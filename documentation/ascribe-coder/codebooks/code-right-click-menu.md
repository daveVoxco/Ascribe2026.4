# Code Right-Click Menu

The right-click menus found in the Codebook pane depend on whether the codebook is locked or unlocked.

### Code Right-Click Menu (Locked Codebook) <a href="#minitocbookmark2" id="minitocbookmark2"></a>

When the codebook is locked, the Code right-click menu has the following options:

<table><thead><tr><th width="216.33331298828125" valign="top">Option</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top"><strong>When you right-click a code &#x26; no codes are selected, these options are available:</strong></td><td valign="top"></td></tr><tr><td valign="top">Code Properties</td><td valign="top">Displays the code properties dialog. For more information, see <a href="edit-code.md">Edit Code</a>.</td></tr><tr><td valign="top">Toggle Focus</td><td valign="top">Allows users to edit the codebook using the keyboard. The focus moves around in response to the up/down arrow keys. For more information, see <a href="use-keyboard-to-edit-codebook.md">Use Keyboard to Edit Codebook</a>.</td></tr><tr><td valign="top">Information</td><td valign="top"><p>Displays the Code Information dialog which lists input ID, output ID, code ID, description, regular expression, hover help, and long help.</p><p>The Where Used section displays the study ID, question ID, number of codes applied, percentage of all responses, percentage of responses coded, and percentage of study respondents.</p></td></tr><tr><td valign="top">Responses</td><td valign="top">A dialog displays with the responses that have this code applied; this option is only available if the code has been applied to a response.</td></tr><tr><td valign="top">Search Any</td><td valign="top"><p>Search Any performs a search for responses that have this code applied. The search uses the options currently in effect in the Search dialog, with these exceptions:</p><ul><li>Regardless of what tab is currently selected in the dialog, the search is performed as if the Find tab were selected</li><li>The Responses containing this Text item is treated as if it were blank</li><li>The Show Only dropdown is treated as if Any (or ALL as appropriate) were selected</li><li>The New Search radio button is treated as if it were selected</li></ul></td></tr><tr><td valign="top">Search Expression</td><td valign="top">This option is available if the code has a regular expression. It searches for responses that match the expression. It has the same effect as clicking on a regular expression in the codebook.</td></tr><tr><td valign="top">Show Parent</td><td valign="top"><p>Codebook scrolls to the parent of the code; the parent is either the net or the subnet, depending where the code is located.</p><p>You can also use the keyboard shortcut of shift/click to move to the parent.</p></td></tr><tr><td valign="top">Select Siblings</td><td valign="top"><p>With codes, siblings are codes or nets that are at the same level of the selected code. Has these options:</p><ul><li><strong>Codes –</strong> Selects and highlights all of the code's sibling codes</li><li><strong>Used codes –</strong> Selects and highlights all of the code's sibling codes which have been applied to responses</li><li><strong>Unused codes -</strong> Selects and highlights all of the code's sibling codes which have not been applied to any responses</li><li><strong>To selected above -</strong> Selects and highlights sibling codes above the code</li><li><strong>To selected below -</strong> Selects and highlights sibling codes below the code</li></ul></td></tr><tr><td valign="top">Insert Code</td><td valign="top">Opens the <a href="edit-code.md">Code Properties dialog</a>, to add a new code below the current code.</td></tr><tr><td valign="top">Delete</td><td valign="top">If a code has not been used, there is an option to delete it.</td></tr><tr><td valign="top">Update Regular Expression Based On Selected Responses</td><td valign="top"><p>Adds regular expression based on selected responses.</p><p>The regular expression field is populated with the selected response or responses if:</p><ul><li>the responses are 50 characters or less.</li><li>the responses do not contain regular expression operators</li><li>the responses do not contain multiple sentences separated by punctuation marks.</li></ul><p>After you click OK, the code is applied to the selected responses.</p></td></tr><tr><td valign="top">Make This Code Singleton / Remove Singleton Property</td><td valign="top"><p>If the code has not been marked as singleton, this option changes the code to singleton. (A singleton code should not be applied to a response with any other code.)</p><p>If the code has been marked as singleton, the option is Remove Singleton Property.</p><p>See <a href="edit-code.md">Singleton</a> for more information. When you mark a code as singleton through the right-click menu, Ascribe checks for violations of the Singleton rule. If there is a violation, a dialog displays with a link to view <a href="codebook-tools.md#singleton">Singleton tab</a> in the Codebook Tools dialog so you can make corrections.</p></td></tr><tr><td valign="top">Make Selected Codes Singleton / Remove Singleton Property From Selected Codes</td><td valign="top"><p>You can select multiple codes and mark them as singleton. (A singleton code should not be applied to a response with any other code.)</p><p>If the selected codes have been marked as singleton, the option is Remove Singleton Property.</p><p>See <a href="edit-code.md">Singleton</a> for more information. When you mark a code as singleton through the right-click menu, Ascribe checks for violations of the Singleton rule. If there is a violation, a dialog displays with a link to view <a href="codebook-tools.md#singleton">Singleton tab</a> in the Codebook Tools dialog so you can make corrections.</p></td></tr><tr><td valign="top"><strong>When you right-click a code &#x26; codes are selected, these options are also available:</strong></td><td valign="top"></td></tr><tr><td valign="top">Search ALL</td><td valign="top"><p>If more than one code is selected, both Search Any and Search All options are available.</p><p>Search All performs a search for responses that have all selected codes applied. The search uses the options currently in effect in the Search dialog, with these exceptions:</p><ul><li>Regardless of what tab is currently selected in the dialog, the search is performed as if the Find tab were selected</li><li>The Responses containing this Text item is treated as if it were blank</li><li>The Show Only dropdown is treated as if Any (or ALL as appropriate) were selected</li><li>The New Search radio button is treated as if it were selected</li></ul></td></tr><tr><td valign="top">Deselect All</td><td valign="top">Deselects and unhighlights any code or net that is selected.</td></tr><tr><td valign="top">Deselect Siblings</td><td valign="top"><p>With codes, siblings are codes that are at the same level of the selected code. Has these options:</p><ul><li><strong>Codes –</strong> Deselects and unhighlights all of the code's sibling codes</li><li><strong>Used codes –</strong> Deselects and unhighlights all of the code's sibling codes which have been applied to responses</li><li><strong>Unused codes -</strong> Deselects and unhighlights all of the code's sibling codes which have not been applied to any responses</li><li><strong>Empty nets -</strong> Deselects and unhighlights any empty nets that are siblings of the code (empty nets are nets without any codes)</li><li><strong>To deselected above -</strong> Deselects and unhighlights sibling codes above the code</li><li><strong>To deselected below -</strong> Deselects and unhighlights sibling codes below the code</li></ul></td></tr></tbody></table>
