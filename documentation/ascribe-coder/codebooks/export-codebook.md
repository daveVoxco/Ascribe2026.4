# Export Codebook

![](https://static.goascribe.com/Help/print_codebook_020521.png)

The Export Codebook feature allows you to export the codebook with various options. The [Codebook Settings](codebook-settings.md) affect how the codebook is displayed in the Codebook pane. These settings are also used when you use the Export Codebook feature.
