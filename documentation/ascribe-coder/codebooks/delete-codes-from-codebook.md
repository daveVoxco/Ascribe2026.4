# Delete Codes from Codebook

![](https://static.goascribe.com/Help/delete_icon_02_071614.gif)

This option deletes selected codes or nets. Codes and nets must be unused in order to delete them. You need to unlock the codebook before you can delete unused codes/nets from the codebook. With the codebook unlocked, select the codes/nets you would like to delete and then click the Delete icon.

A confirmation dialog displays with the number of codes or nets that will be deleted, as shown below. Click Delete to continue or Cancel to discontinue the process.
