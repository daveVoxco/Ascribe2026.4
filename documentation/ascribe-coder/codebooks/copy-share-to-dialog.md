# Copy/Share To Dialog

Navigate: Studies/Right-click a study/Select Questions

For general information about copying or sharing codebooks, see [Share and Copy Codebooks](share-and-copy-codebooks.md).

The Copy/Share To dialog allows you to share the codebook of the selected question with any number of other questions in the study. **The questions you share the codebook to must have no coded responses.**

In this method, you select a **source question** which contains the codebook you want to copy/share. To start the process, right-click your source question and select Copy/Share>Copy/Share Codebook To. The Copy/Share To dialog opens, and the source question remains highlighted behind the dialog.

Here is the format of the dialog box:

<table><thead><tr><th width="213.3333740234375" valign="top">Option</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top">Questions</td><td valign="top"><p>We can also refer to these as target questions. These questions can have their codebooks replaced with the codebook of the source question.</p><p>The target questions may have a codebook, but they have not been used to code responses. The number in brackets before the question ID shows the number of codes in the codebook. If there is no number in brackets, then the codebook is empty. If the question's codebook is not empty, you will get a message which asks if you want to replace the codebook.</p><p>Click Add All to add all questions in the list to the Selected Questions side (right side of dialog.) To add individual questions, click the plus sign next to each question.</p><p>To remove a question from the right side, click the minus sign next to it or click Remove All to remove all of the questions.</p></td></tr><tr><td valign="top">Make A COPY Of The Codebook</td><td valign="top">Makes a copy of the codebook.</td></tr><tr><td valign="top">SHARE The Codebooks</td><td valign="top">Shares the codebooks.</td></tr></tbody></table>

Click OK to finish the procedure or click Cancel to exit without copying or sharing the questions.
