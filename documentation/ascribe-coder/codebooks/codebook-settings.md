# Codebook Settings

![](https://static.goascribe.com/Help/codebook_settings_icon_071514.gif)

The Codebook Settings feature allows you to customize the display of the codebook. The dialog has four tabs: [Show](codebook-settings.md#minitocbookmark2), [When Locked](codebook-settings.md#minitocbookmark3), [When Unlocked](codebook-settings.md#minitocbookmark4), and [Appearance](codebook-settings.md#minitocbookmark5).

### Show <a href="#minitocbookmark2" id="minitocbookmark2"></a>

Here are the options for the Show tab (this tab means that these fields will display whether the codebook is locked or unlocked):

<table><thead><tr><th width="198" valign="top">Option</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top"><strong>Codes</strong></td><td valign="top"></td></tr><tr><td valign="top">Input ID</td><td valign="top"><p>Displays the Input Code ID for codes in the codebook; the input ID displays in italics.</p><p>The input code value is used for automatically coding responses to closed-ended, other specify, and value questions. The field may be blank if you will not use this codebook for automatic coding of closed-ended responses.</p></td></tr><tr><td valign="top">Output ID</td><td valign="top"><p>Displays the Output Code ID for codes in the codebook; the output ID displays in normal font to distinguish it from the input ID when displaying both.</p><p>Ascribe writes this field to the output file when the coded responses are downloaded. It is the “value” or outputID of the code. The codebook displays the field to the left of the code description. It can be a number or text.</p><p>If you select the no duplicate outputID’s option in the codebook properties dialog, Ascribe checks for duplicate values in the codebook. If a duplicate is found, Ascribe changes the value you entered here to a large number. The large number reminds you to select a different and unique value.</p><p>The field may be blank. Even if the no duplicate outputID's option is set, you may have multiple codes with no outputID. These are not considered to be duplicates.</p></td></tr><tr><td valign="top">Code ID</td><td valign="top">Displays the Code ID for the codes in the codebook - this field is for internal use by Ascribe Support for certain data collections systems....users do not need to do anything with this field.</td></tr><tr><td valign="top">Regular Expression</td><td valign="top"><p>Displays the regular expression for the codes in the codebook.</p><p>An expression is used to match words in a response. It helps the coder to pick the proper code for a verbatim.</p><p>During coding, Ascribe checks the response against all of the expressions in the codebook. When a match is found, Ascribe highlights and underlines the expression word or words found in the response. The coder clicks the highlighted words, and the corresponding code is placed in the selected codes pane. See <a href="regular-expressions.md">Regular Expressions</a> for more information. The field may be blank if you do not want to use regular expressions.</p></td></tr><tr><td valign="top">Counts</td><td valign="top"><p>Displays the frequency and percentage for the codes in the codebook; the counts are updated as you code.</p><p>The count displays first, and then the percentage as in this example:</p><p><img src="https://static.goascribe.com/Help/Count_and_percentage.gif" alt="" data-size="original"></p><p><mark style="color:$danger;"><strong>94</strong></mark> is the number of responses which received the code.</p><p>The percentage (<mark style="color:$danger;"><strong>8%</strong></mark>) is based on the total number of responses in the question(s) being coded.</p></td></tr><tr><td valign="top">Created By User</td><td valign="top">Displays the user who added the code next to the code; not available for codes created prior to version 9.0 release. Hover over the user name to see the date the code was added. This information is not available when a study is saved and restored.</td></tr><tr><td valign="top"><strong>Nets</strong></td><td valign="top"></td></tr><tr><td valign="top">Input ID</td><td valign="top">Displays the Input Code ID for the nets in the codebook.</td></tr><tr><td valign="top">Output ID</td><td valign="top">Displays the Output Code ID for the nets in the codebook.</td></tr><tr><td valign="top">Code ID</td><td valign="top">Displays the Code ID for the nets in the codebook.</td></tr><tr><td valign="top"><strong>Help</strong></td><td valign="top"></td></tr><tr><td valign="top">Hover Help</td><td valign="top">This field provides short instructions to the coders for this code. If you select this option, the hover help displays for each code that has a hover help entry. The field may be blank if you do not want to use hover help.</td></tr><tr><td valign="top">Long Help</td><td valign="top">This field provides longer instructions to the coders for this code. You can enter as much information as you want or the field may be blank.</td></tr></tbody></table>

### When Locked <a href="#minitocbookmark3" id="minitocbookmark3"></a>

Here are the options for the When Locked tab:

<table><thead><tr><th width="224.6666259765625" valign="top">Option</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top"><strong>Show</strong></td><td valign="top"></td></tr><tr><td valign="top">Borders</td><td valign="top">Nets and codes are displayed with a border around them.</td></tr><tr><td valign="top">Selection Checkbox</td><td valign="top">Allows user to select a specific code or codes in the codebook pane. The selection checkbox can be used in conjunction with the <a href="../responses-settings.md#minitocbookmark2">Apply Selected Codes Button</a> to do coding.</td></tr><tr><td valign="top">Information Button</td><td valign="top">Displays code properties (input/output/code ID, code description, regular expression, and hover/long help). The study and question where the code is used as well as the number responses applied to the code are also displayed.</td></tr><tr><td valign="top">Icon Tooltips</td><td valign="top">When the user hovers over an icon (selection checkbox, information button, etc) within a codebook, a balloon displays with help for that feature.</td></tr><tr><td valign="top">Hover Help Tooltips</td><td valign="top">When the user hovers over a net or code within a codebook, a small box displays with the hover help (from the code properties dialog) for that net or code.</td></tr><tr><td valign="top"><strong>Codes Only View</strong></td><td valign="top"></td></tr><tr><td valign="top">Show Codes Only View</td><td valign="top">Displays codes in order by the option selected in the Sort Codes By box without any nets or subnets. You can add codes in this mode; they will display at the bottom of the codebook when Show Codes Only View is toggled off. You can apply codes, swap codes, and change the properties of codes. (When you are in Show Codes Only View, the codebook node will be missing, and not all right-click menu options are available.)</td></tr><tr><td valign="top">Sort Codes By</td><td valign="top">Changes the order of the codes in the codebook; the options are: codebook order, input ID, output ID, description, regular expression, hover help, and long help.</td></tr><tr><td valign="top">Reverse The Sort</td><td valign="top">Reverses the order of the codes in the codebook by the sort option selected in the Sort Codes By box.</td></tr></tbody></table>
