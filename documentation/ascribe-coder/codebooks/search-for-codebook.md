# Search for Codebook

The Search for Codebook dialog is used in Ascribe Coder and Dual Codebooks. It allows you to find a codebook, but the dialog has different functionality depending on the page.

In Ascribe Coder:

* The dialog only displays if the codebook is empty. (If a codebook is not empty, the [Search Codebook](search-codebook.md) dialog displays.)
* The dialog allows you to copy or share the entire codebook.

In Dual Codebooks:

* The dialog displays when you click the Left Codebook or Right Codebook buttons.
* You can copy the entire codebook.
* You can select the codes or nets that you want to copy.

The Search for Codebook dialog contains the [Options](search-for-codebook.md#minitocbookmark2) pane, the Search text box, and Search Results.

After you make selections in the Options pane, enter the appropriate character string in the Search text box and click the Search button.

Only the first 20 codebooks/questions/studies display. The first 10 codes in the codebook display.

Click the codebook node to see complete codebook information.

If you are in Ascribe Coder, you can click Copy Codebook or Share Codebook. If you are in Dual Codebooks, click OK to display the codebook.
