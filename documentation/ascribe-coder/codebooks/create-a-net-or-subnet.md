# Create a Net or Subnet

The codebook can be locked or unlocked when you create nets or subnets.

**To create a net, right-click a code in the codebook and select Insert Code.** The Code Properties dialog opens. Fill in the fields as needed. To make the code a net, click the Net check box.

You can tab through each field to reach the Net field, and then press the space bar to put the check mark in the box.

![](https://static.goascribe.com/Help/Code_properties_for_a_net.gif)

**To create a subnet, right-click a net and select Insert Code/Into.** The Into option indicates that you want the code or subnet to be part of the net. When you fill in the Code Properties dialog, click the Net check box as shown above.

### Change a Code to a Net or Subnet

When the codebook is unlocked, you can right-click an unused code and select Change to Net. Whether the code becomes a net or subnet depends on its location in the codebook. For example, if the code is part of a net, it will become a subnet. If a code is not part of a net, it will become a net.
