# Codebook Tools

![](https://static.goascribe.com/Help/codebook_tools_icon_03_071514.gif)

The Codebook Tools dialog has these tabs: [Expression List](codebook-tools.md#expression-list), [Singleton](codebook-tools.md#singleton), [Duplicates List](codebook-tools.md#duplicates-list), and [Usage](codebook-tools.md#usage).

### Expression List

This tab lists all of the regular expressions used in the codebook. The output ID, code description, and regular expression are listed. Click on any field to find it in the codebook. The list can also be copied to Excel; just click the Excel icon.

### Singleton

This tab lists any codes marked as singletons which are applied with other codes. To view the affected responses, right-click the code and select Search Any.

### Duplicates List

This tab provides information about duplicate input ID, output ID, code ID, code descriptions, and regular expressions. If there is a duplicate, the Duplicates List tab will be highlighted in yellow, and the appropriate tab will be highlighted in yellow.

### Usage

To see where the codes have been used, click the Show Usage button. Display is restricted to the first 1000 codes and first 10 questions.

If the codebook was used in multiple questions, each question will be displayed in a separate column.
