# Search Responses

The Search Responses dialog allows you to display responses, replace text, and find inconsistencies in coding or translations. The dialog has three tabs: [Find](search-responses.md#minitocbookmark3), [Replace](search-responses.md#minitocbookmark4), and [Inconsistencies](search-responses.md#minitocbookmark5).

The Search Responses icon is on the Response Pane Toolbar:

![](https://static.goascribe.com/Help/search_responses_icon_02_071514.gif)

The Search Responses dialog looks like this:

![](https://static.goascribe.com/Help/search_responses_111720.png)

The Search Again option will use the settings in the Search Responses dialog and provide the same search. It can act as a screen refresh or repeat the search that you last did. For more information, see [Search Again](search-again.md).

When you display responses, you receive messages above the responses that are displayed. For more information, see [Statistics for Displayed Responses](statistics-for-displayed-responses.md).

The Search Responses dialog  has a minimize button in the title bar. When you minimize the dialog, it automatically moves to the Find tab. The options specified on that tab remain in effect, but only the _Responses Containing this Text_ box is displayed. This provides more screen area for your view of the responses when performing multiple text searches.

## Keyboard Shortcuts <a href="#minitocbookmark2" id="minitocbookmark2"></a>

To set a keyboard shortcut to display the Search dialog, click the Navigation icon and select Tools>Keyboard Shortcuts. You can change the letter in the field called Search Responses. The shortcut defaults to Ctrl + R.

Use Ctrl/click to perform the last search you did; it uses the settings in the Search dialog to display responses and does not display the Search dialog.

## Paging of Large Response Sets <a href="#minitocbookmark6" id="minitocbookmark6"></a>

To enhance performance and improve productivity when working with large numbers of responses, Ascribe Coder supports paging of responses. Ascribe Coder will display a maximum of 30,000 responses, or a smaller number if specified in the Search dialog. When there are more responses meeting the search criteria than the selected maximum, the Search Again button will display the current page, and the number of additional pages to view. Click the Search Again button to display the next set of responses, or Ctrl-click to return to the first page of responses.
