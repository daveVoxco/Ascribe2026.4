# Ascribe Coder

_Navigate: Right-click in white space/Select Ascribe Coder_\
&#xNAN;_&#x53;upervisor/Studies/Right-click study/Select Questions/Right-click a question/Select Ascribe Coder_

Ascribe Coder merges the functionality of three previous pages: Review Responses, Edit the Codebook, and the Single Response Coding page. These pages are no longer available.

The page displays the codeframe on the right and the responses to be coded on the left. The questions being coded appear in a pane at the bottom. All panes are resizable by dragging the border.

Ascribe Coder is supported in Chrome, Firefox, and Safari on Mac

Actions are invoked by left-clicks on buttons and icons, and right-clicks for context-specific actions on codes and responses.

The codeframe can be unlocked by clicking the lock icon. When locked (the normal state), the structure of the codeframe cannot be changed. The codeframe can be unlocked by only one user at a time.

## Navigation Directly to Ascribe Coder <a href="#minitocbookmark2" id="minitocbookmark2"></a>

You can navigate directly to Ascribe Coder from the Home page by clicking the Coder icon.

When you navigate to Ascribe Coder in this fashion, you are greeted with a dialog allowing you to pick which question to code. You may choose from the 20 most recent ways you have accessed Ascribe Coder, the questions currently assigned to you to code, or you may search for a study and then a question to code.

Within Ascribe Coder, you can conveniently choose to code something else by choosing Ascribe Coder from the navigation menu. This allows you to move from one set of questions to code to another without leaving Ascribe Coder.

## Page Layout <a href="#minitocbookmark3" id="minitocbookmark3"></a>

Ascribe Coder has three panes. The left side of the screen is the Response Pane, and the right side is the Codebook Pane. The bottom of the screen has the Question Information Pane. When you first open Ascribe Coder, the Response Pane will be blank - use the Search function to display responses.

## Coding Mode <a href="#minitocbookmark7" id="minitocbookmark7"></a>

Ascribe Coder has two coding modes: single response and multiple response. Multiple response allows users to work with multiple responses. Single response allows users to display one response at a time.

A _Code single response_ checkbox is in the Responses tab of the Response Settings dialog. This checkbox toggles the display between single and multiple response modes. As a shortcut, you can ctrl-click on the Settings icon to toggle between single and multiple response modes without the need to open the dialog.

When coding a single response at a time, the response presented to the user is locked for the time it is presented, so that no other user in the single response coding mode will be presented with the same response.
