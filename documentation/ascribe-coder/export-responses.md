# Export Responses

![](https://static.goascribe.com/Help/Export_Responses.png)

When you click the Export Responses icon, the Export dialog displays. Note that the Export Responses icon may be hidden through the [Tools setting](responses-settings.md#minitocbookmark5) on the Appearance tab of Responses Settings. You can also access the Export dialog through the navigation menu option of Tools.

The Export dialog allows you to export responses in Excel or Word format. Here is the dialog:

![](https://static.goascribe.com/Help/Exxport_responses_dialog_020521.gif)

You have many options for the export.

You can choose which responses are exported; these choices are listed in the dialog and are described below.

You can also include the following information: coding quality status, study ID, question ID, respondent ID, translation, transcription, and notes. These fields will export if you select them on the [Responses tab of Responses Settings](responses-settings.md#minitocbookmark2). Also, the reviewed status of the response, translation, transcription, and notes will display when you export those fields. Related Responses will also export if you select to display them in [Search Responses.](search-responses.md)

You have the option of including the input ID, output ID, user name of the coder and date coded. These fields will export if you select them on the [Applied Codes tab of Responses Settings](responses-settings.md#minitocbookmark4).
