# Samples Page

_Supervisor/Samples_

_Questions page/Right-click a question/Samples/View_

The Samples page displays all of the permanent samples that exist on the account. [Temporary samples](create-a-sample.md#minitocbookmark3) are not listed here. (If you navigate to the Samples page from a question, it displays only samples for that question.)

## Right-click Menu for Samples Page <a href="#minitocbookmark2" id="minitocbookmark2"></a>

Here are the right-click menu options for the Samples page:

| Option        | Description                                                                      |
| ------------- | -------------------------------------------------------------------------------- |
| Properties    | Displays the properties dialog where you can edit the ID and description fields. |
| Ascribe Coder | Navigates to the [Ascribe Coder](./) page and selects the sample as the source.  |
