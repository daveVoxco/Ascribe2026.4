# Codebook Change Report

This report tracks every codebook change made within the manual coding interface ([ascribe-coder](../ascribe-coder/ "mention")), listing details such as account ID, username, study, question, timestamp, and the type of activity (edit, delete, move, create).

<figure><img src="../../.gitbook/assets/image (83).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
#### Note

Changes may take a few minutes to show up in the report.
{% endhint %}
