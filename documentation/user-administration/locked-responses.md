# Locked Responses

_Navigate: Administrator/Locked Responses_

The Locked Responses page displays responses that are currently locked to prevent concurrent editing by multiple users.

To maintain data integrity, you should only manually unlock responses to clear abandoned sessions, ensuring the queue remains accessible for your team.

## Lock Scenarios

<table><thead><tr><th valign="top">Status</th><th valign="top">Cause</th><th valign="top">Action Required</th></tr></thead><tbody><tr><td valign="top">Active Session (Normal)</td><td valign="top">A user is actively viewing the response in Single Coding mode.</td><td valign="top">None. Do not manually unlock. It unlocks automatically when the user moves to another response.</td></tr><tr><td valign="top">Abandoned Session (Abnormal)</td><td valign="top">A user closed their browser without properly logging out.</td><td valign="top">Unlock manually. Otherwise, the response remains locked for 1–2 hours until routine system maintenance runs.</td></tr></tbody></table>

## How to Unlock a Response

1. Navigate to **Administrator** > **Locked Responses**
2. Right-click the target response and select Unlock
3. Click OK to confirm
