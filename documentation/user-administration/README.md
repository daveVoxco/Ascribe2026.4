# User Administration

There are two types of user accounts in Ascribe:

* **Associates -** These users have access to all studies in your Ascribe site, although their privilege level can restrict access to those studies.
* **Contacts** **-** These users are associated with companies in Ascribe, and have access only to those studies assigned to that company. Again, the specific access rights the contact has depends on the privileges assigned to the contact.

Administrator privilege is required to create associate accounts. Supervisor privilege is required to create companies and contacts.

To create associate accounts, see [Add/Edit an Associate](associates.md#minitocbookmark4).

To create contact accounts, see [Contacts](contacts.md).

## Privilege Levels <a href="#minitocbookmark2" id="minitocbookmark2"></a>

Both associates and contacts have privilege levels assigned to them. Generally these privileges mirror the Ascribe navigation menu. So, for example, giving supervisor privileges to an associate grants them access to the functions in the supervisor portion of the menu.

If you clear all privileges for an associate or contact, the user account is disabled and the person cannot log in to Ascribe. The same is true if you delete the associate or contact.

All privilege levels are available to associates. A restricted set of privileges is available to contacts.
