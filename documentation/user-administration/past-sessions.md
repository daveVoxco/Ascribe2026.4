# Past Sessions

Navigate: Administrator/Past Sessions

This table shows your login sessions for the selected time period. Sessions that are currently active are not shown in this report. To view current sessions, use the [Open Sessions](../get-started/open-sessions.md) report.

{% hint style="info" %}
#### Note

Login hours do not "double count" hours for which the user had more than one active session. For example, if a user logs in to Ascribe in two browsers simultaneously and remains logged in for one hour in both browsers, session hours will report two hours, and login hours only a single hour.
{% endhint %}
