# Site Configuration

_Navigate: Administrator/Account Options_

Administrators can set default values for studies, questions, codebooks, and load file types on the Account Options page. The values specified will be used as the initial values displayed when adding these items from Ascribe. They also are the values used when studies, questions, codes, etc., are added in a batch mode.

{% hint style="info" %}
#### Note

These are default values only. The settings always can be changed in the appropriate editing functions. Also, changing the default has no effect on existing value.
{% endhint %}
