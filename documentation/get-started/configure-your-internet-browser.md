# Configure Your Internet Browser

No special configuration is needed for Chrome, Firefox, Microsoft Edge, and Safari on Mac OSX. These browsers are supported on Ascribe.

## Use Secure Communication <a href="#minitocbookmark2" id="minitocbookmark2"></a>

We recommend that you use the secure https protocol when connecting to the Ascribe website. You do this by using https: in the URL you enter in your browser to connect to Ascribe. This URL has the secure protocol:

https://app.goascribe.us/ascribe/

This URL does not have the secure protocol:

http://ascribe.goascribe.com/Ascribe

Your account may be configured to switch automatically to the secure protocol when you log in. If it is not configured this way, we still recommend that you use the secure protocol. You can tell if you are using the secure protocol by checking for a padlock icon on the status bar of your browser.
