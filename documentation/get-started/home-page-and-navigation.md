# Home Page and Navigation

Almost all pages have a navigation icon or hamburger icon on the top left of the page. Click the icon to display the navigation menu.

If the page does not have a navigation icon, right-click on the page for the navigation menu. Pages without a navigation icon include Edit Responses, Edit Respondent, Transcribe, and Translate.

The navigation and features available to you depend on the privilege level of your login account. Your administrator sets the privilege level for each user.

You should not use the Back button on your browser to navigate around Ascribe. Because the content of the site is dynamic (it can change each time it is displayed), the Back button can show you incorrect results by displaying a page image saved by your browser.

## Home Page

The Ascribe Home page also additional navigation options. The middle of the page displays icons for the main applications. Click the icon associated with the application or the application name to navigate there.

Additionally, Coder and CXI Inspector have shortcuts to related pages; hover over the application icon to see the three-dot menu button associated with it

The hamburger icon in the blue area has additional options: Help, Release Notes, Jobs, Open Sessions, Agreements, Downloads, and User Options.
