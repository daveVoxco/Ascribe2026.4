# Log Out

To log out of Ascribe, use the Log Out option in the navigation menu in whatever window you are in. You should always log out of from Ascribe. If you do not log out, you may leave responses 'locked' so that others cannot code them. For example, if you simply close your browser, the response you were coding will remain locked, awaiting your codes. This action prevents others from coding this response. (To unlock a response, see [Locked Responses](../user-administration/locked-responses.md).)

When you log out, Ascribe computes the amount of time you were logged in. When computing your login time, Ascribe checks whether you had more than one open browser session. If you did, it calculates your login time for the non-overlapping periods only.
