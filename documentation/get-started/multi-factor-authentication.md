# Multi-Factor Authentication

Multi-factor authentication (MFA) means that a user must provide more than one way to verify identity when logging into an account. It adds more security to the account.

In order to use MFA, you must be a single sign-on user and you must not use an external identity provider. If you are using an external identity provider, then you have to use that provider for MFA.

## Enable MFA

When you use an authenticator app, the similar steps as these are required:

![](https://static.goascribe.com/Help/MFA_info.jpg)

When you scan the QR code, it produces a code that you should enter as shown in Step 3.

The next time you log in, you will receive a dialog which prompts you to enter the MFA code. Just open your authenticator app, copy the code for Ascribe, and paste it into the dialog.

## Save the QR Code

In the form that displays the QR code, there is a Download QR code button. This saves the QR code as an image file to your computer. This is handy if you use multiple browsers. By saving the QR code image, you can set up your authenticator app on other browsers by opening the QR code file in the browser and trying to scan it.
