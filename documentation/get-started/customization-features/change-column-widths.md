# Change Column Widths

On many Ascribe pages, you can simply drag the column header divider to increase or decrease the column width. For the Studies page and the Questions page, change the column widths through the right-click menu option Change Column Widths. A dialog box displays with the defaults for each column. The widths are shown in pixels. Increase the number to make the column wider, and decrease the number to make the column more narrow. After you change the widths, click OK to save your changes. Click cancel if you do not wish to make any changes.
