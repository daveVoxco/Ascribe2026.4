# User Options

From the General menu, select User Options. This page allows users to set default behaviors for selected aspects of Ascribe operation.

* Session time is displayed in the user's menu.

<figure><img src="../../../.gitbook/assets/image (43).png" alt=""><figcaption></figcaption></figure>

{% hint style="warning" %}
#### Important

**When a user has single sign-on credentials**, the SSO identity applies to all accounts where SSO is set up. Therefore, the first name, last name, full name, email address, phone number and address can only be changed by the user on the User Options page.
{% endhint %}
