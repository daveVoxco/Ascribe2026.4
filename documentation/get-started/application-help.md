# Application Help

The help system is a feature that allows the user to obtain information about usage of the Ascribe software and updates. Ascribe Help provides the user with definitions about the different functions in Ascribe.

The help system is context sensitive. Users can choose **Help** from the navigation menu to get information about the current page/function or by pressing F1. The help system also can be accessed from various dialog boxes throughout the software. When Help is selected, a new browser window opens with information about the current area of Ascribe. It can be minimized or closed without interrupting your Ascribe session.

To print a single page of the documentation, click the Table of Contents link in the Help window and then click the Print button in the Help toolbar.
