# Phrase Analyzer II Settings

This dialog contains settings for automatic marking, applying codes, and display. Here are the options:

<table><thead><tr><th width="215.333251953125" valign="top">Option</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top">For Automatic Marking Use</td><td valign="top"><p>This option is used to match segments to existing codes in the codebook based on these rules:</p><ul><li>If the input ID of the code matches the segment by case insensitive comparison, it is a match</li><li>Otherwise, if the regular expression of the code matches the segment, it is a match</li><li>Otherwise, if the description of the code is the same as the segment it is a match.</li></ul></td></tr><tr><td valign="top">Apply Codes</td><td valign="top">Add Orphaned Segments to Notes moves segments without marks or potential codes to the Notes field.</td></tr><tr><td valign="top">Display</td><td valign="top"><p>These options change the display:</p><ul><li>Monospace Font for Segment Text - Because Phrase Analyzer II is based on Ascribe Coder, this option displays the segments in a different font which makes it easier to distinguish Phrase Analyzer II from Ascribe Coder.</li><li>Hide Logo - Hides the Ascribe Coder logo which is displayed at the bottom of the screen.</li></ul></td></tr></tbody></table>
