# Illustrator Wizard

The Wizard guides users through the steps of creating visualizations. The Wizard dialog has these tabs: [Visualizations](illustrator-wizard.md#visualizations), [Questions](illustrator-wizard-questions.md), [Filters](illustrator-wizard-filters.md), and [Options](illustrator-wizard-options.md).

Click the Wizard icon <img src="https://static.goascribe.com/Help/Wizard_icon.gif" alt="" data-size="line"> to display the dialog.

If you want to use the Wizard every time you create a new illustration, click the checkbox at the bottom of the dialog:

![](https://static.goascribe.com/Help/Checkbox_for_displaying_wizard.gif)

If you don't want to use the Wizard every time, then unselect the checkbox.
