# Save Illustration

![](https://static.goascribe.com/Help/Save_and_Save_As.gif)

You have two ways to save an illustration. To save it with the current name, click the Save button.

To save the illustration with a different name, click the Save As button. A dialog displays where you enter the new ID and optional label. It copies the existing illustration and gives it a different name.

When you save an illustration, you are actually saving a string of instructions. You are not saving the data, charts or tables.
