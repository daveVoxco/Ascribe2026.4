# Manipulate Visualizations

![](https://static.goascribe.com/Help/Manipulate_visualizations.gif)

The gray toolbar provides several ways to manipulate visualizations. The visualization itself also provides way to change its size and properties.

## Gray Toolbar Options

Here are some ways to change the visualization with options on the gray toolbar:

<table><thead><tr><th width="230.6666259765625" valign="top">Option</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top">Select All Visualizations</td><td valign="top"><p>Selects all of the visualizations on the canvas. The common properties of the visualizations display on the right side of the screen.</p><p>Keyboard shortcut: Ctrl/A</p><p>To unselect all, click anywhere on the canvas or click ESC.</p></td></tr><tr><td valign="top">Cut</td><td valign="top"><p>Allows you to cut (and then paste) a visualization to another canvas.</p><p>Keyboard shortcut: Ctrl/X</p></td></tr><tr><td valign="top">Copy</td><td valign="top"><p>Allows you to copy a visualization to another canvas.</p><p>Keyboard shortcut: Ctrl/C</p></td></tr><tr><td valign="top">Paste</td><td valign="top"><p>Allows you (to cut) and then paste a visualization to another canvas</p><p>Keyboard shortcut: Ctrl/V</p></td></tr><tr><td valign="top">Duplicate</td><td valign="top"><p>Allows you to create a duplicate of the visualization on the same canvas.</p><p>Keyboard shortcut: Ctrl/D</p></td></tr><tr><td valign="top">Delete</td><td valign="top">Deletes the selected visualization</td></tr></tbody></table>

## Visualization Options

The visualization has some options for altering appearance:

![](https://static.goascribe.com/Help/Visualization_manipulation.gif)

<table><thead><tr><th width="223.99993896484375" valign="top">Option</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top">Slideshow Mode</td><td valign="top"><p>Expands visualization to full screen.</p><p>When the visualization is full screen, click the resize button (<img src="https://static.goascribe.com/Help/resize_button.gif" alt="" data-size="line">) to return to the previous size.</p><p>For more information, see <a href="slideshow-mode.md">Slideshow Mode</a>.</p></td></tr><tr><td valign="top">Add Note</td><td valign="top">Use this option to add a note to the visualization. The note is hidden, but the pencil icon turns yellow to indicate there is a note. Click the icon to add or view the note.</td></tr><tr><td valign="top">Delete</td><td valign="top">Deletes the selected visualization</td></tr><tr><td valign="top">Resizer Handle</td><td valign="top">Allows you to resize the visualization</td></tr></tbody></table>

When a visualization is selected, the options for the visualization display on the right side of the screen. These options allow you to change the appearance of the visualization. For more information, see the help topics for each visualization.
