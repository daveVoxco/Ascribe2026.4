# Co-occurrence Chart

A co-occurrence chart displays how frequently codes and/or nets were applied. It also displays which codes and/or nets were applied together the most frequently.

To create a co-occurrence chart, add a visualization box to a canvas, select a question, and then select Co-Occurrence from the visualization type drop-drown.

![](https://static.goascribe.com/Help/Co-occurrence_chart_mar29.gif)

The co-occurrence chart options are not always visible. To see them, click the chart. The chart frame darkens, which indicates that it is selected, and the options display on the right side of the screen. Here are the co-occurrence chart options:
