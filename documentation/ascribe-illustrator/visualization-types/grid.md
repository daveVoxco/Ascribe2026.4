# Grid

The Grid visualization displays the shared questions across codebooks in the study or topics across questions used in the analysis.

Note there are two options involving multiple studies.

One option requires the [illustration to be created from multiple studies](../#create-an-illustration-from-multiple-studies). If the illustration was created this way, the Grid displays questions which have the same codebook; the questions do not have to be shared; however, each code from each codebook is displayed.

The second option does not require that you create an illustration from multiple studies; instead, you can load the shared questions from other studies using the [Grid Across Studies option in the Wizard](../illustrator-wizard.md#visualizations) or the [Multi-Studies option](grid.md) in the Grid property pane. Questions must be shared across studies, and these questions will only be used in Grids.&#x20;

To create a grid chart, add a visualization box to a canvas, select a question, and then select Grid from the visualization type drop-drown.

![](https://static.goascribe.com/Help/Create_a_grid_chart.gif)

&#x20;
