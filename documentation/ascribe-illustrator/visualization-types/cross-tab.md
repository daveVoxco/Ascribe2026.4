# Cross-Tab

To create a cross-tab, add a visualization box to a canvas, select a question, and then select Cross-Tab from the visualization type drop-drown.

![](https://static.goascribe.com/Help/Create_cross-tab.gif)

The cross-tab options are not always visible. To see them, click the chart. The chart frame darkens, which indicates that it is selected, and the options display on the right side of the screen. Here are the cross-tab options:
