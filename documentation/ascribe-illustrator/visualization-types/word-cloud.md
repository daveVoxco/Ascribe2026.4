# Word Cloud

To create a word cloud, add a visualization box to a canvas, select a question, and then select Word Cloud from the visualization type drop-drown.

You cannot create word clouds for illustrations created from inspections.

![](https://static.goascribe.com/Help/Create_word_cloud.gif)

The word cloud options are not always visible. To see them, click the chart. The chart frame darkens, which indicates that it is selected, and the options display on the right side of the screen. Here are the word cloud options:
