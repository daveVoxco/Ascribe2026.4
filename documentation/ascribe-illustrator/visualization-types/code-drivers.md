# Code Drivers

This visualization helps the user locate which codes or combination of codes most influences ("drives") a specific dependent code. For example, it will tell something like "Males from the South who drink brand A" (a combination of 3 codes coming from 3 different questions) have a higher tendency than the rest of the population to buy brand B.

To create a code drivers chart, add a visualization box to a canvas, select a question, and then select Code Drivers from the visualization type drop-drown. Next, select at least one predictor question and select one dependent code in the Options area.

You cannot create code drivers charts for illustrations created from inspections.

![](https://static.goascribe.com/Help/Create_code_drivers_chart.gif)

The code drivers chart options are not always visible. To see them, click the chart. The chart frame darkens, which indicates that it is selected, and the options display on the right side of the screen. Here are the options:
