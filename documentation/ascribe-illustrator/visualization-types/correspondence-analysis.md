# Correspondence Analysis

Correspondence analysis is a graphical technique that lets you visualize the content of a cross-tab in a 2D plane. The idea behind it is to look at row profiles and column profiles (i.e., how do rows vary across banners and vice versa, rows that have the tendency to behave similarly across banners will be close to each other on the chart.) Once the row profiles and column profiles have been determined, some matrix algebra is required to make the rows and columns spatial representations fit on the same dual plane. It is like factor analysis but for categorical data.

To create a correspondence analysis chart, add a visualization box to a canvas, select a question, and then select Correspondence Analysis from the visualization type drop-drown. Next, select at least one banner question in the Options area.

![](https://static.goascribe.com/Help/Create_a_correspondence_analysis.gif)

The chart options are not always visible. To see them, click the chart. The chart frame darkens, which indicates that it is selected, and the options display on the right side of the screen. Here are the options:
