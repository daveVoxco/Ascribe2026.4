# Question Drivers

This visualization type lets the user see which question or combination of questions are more responsible than others to determine the frequency of a specific code. It is based on the "CHAID" (Chi-square automatic detection) algorithm.

To create a question drivers chart, add a visualization box to a canvas, select a question, and then select Question Drivers from the visualization type drop-drown. Next, select at least one predictor question and select one dependent code in the Options area.

You cannot create question drivers charts for illustrations created from inspections.

![](https://static.goascribe.com/Help/Create_a_question_driver_chart.gif)

The question drivers chart options are not always visible. To see them, click the chart. The chart frame darkens, which indicates that it is selected, and the options display on the right side of the screen. Here are the options:
