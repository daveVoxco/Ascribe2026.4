# Verbatim

The verbatim chart acts a drill-down for the various visualizations. To create a verbatim chart, add a visualization box to a canvas, select a question, and then select Verbatim from the visualization type drop-drown.

You cannot create verbatim charts for illustrations created from inspections.

![](https://static.goascribe.com/Help/Create_verbatim_chart.gif)

The verbatim options are not always visible. To see them, click the chart. The chart frame darkens, which indicates that it is selected, and the options display on the right side of the screen. Here are the verbatim chart options:
