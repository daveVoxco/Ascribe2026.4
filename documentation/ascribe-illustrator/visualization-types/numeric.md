# Numeric

The Numeric chart is a special type of visualization that works only if the data contains numbers (meaning numbers in the verbatim field.) In that case, it will summarize that data by providing measures of central tendency such as the average, the median and the mode as well as measures of dispersion such as the standard deviation and the inter quartile range. In addition, a box plot will be rendered.

To create a numeric chart, add a visualization box to a canvas, select a question, and then select Numeric from the visualization type drop-drown.

You cannot create numeric charts for illustrations created from inspections. &#x20;

![](https://static.goascribe.com/Help/Create_Numeric_chart.gif)

The options are not always visible. To see them, click the chart. The chart frame darkens, which indicates that it is selected, and the options display on the right side of the screen. Here are the options:
