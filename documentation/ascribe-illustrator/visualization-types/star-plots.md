# Star Plots

The purpose of a star plot is to see how a code or net varies across a series of attributes or banners. Each code or net is represented by a star, and each attribute/banner is represented by a slice.

To create a star plot, add a visualization box to a canvas, select a question, and then select Star Plots from the visualization type drop-drown. Next, select a question from the Banner drop-down in the options area.

![](https://static.goascribe.com/Help/Create_a_star_plot.gif)

The star plot options are not always visible. To see them, click the chart. The chart frame darkens, which indicates that it is selected, and the options display on the right side of the screen.

Note that star plots cannot be created from grouped topics.
