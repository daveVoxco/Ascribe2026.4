# Hi Block Chart

The Hierarchical Block (or Hi Block) chart represents the hierarchical structure of a codebook (i.e., nets, sub nets, and codes) and takes the frequencies into account as well.

&#x20;To create a hi block chart, add a visualization box to a canvas, select a question, and then select Hi Block Chart from the visualization type drop-drown.

![](https://static.goascribe.com/Help/Create_hi_block_chart.gif)

The hi block chart options are not always visible. To see them, click the chart. The chart frame darkens, which indicates that it is selected, and the options display on the right side of the screen. Here are the hi block chart options:
