# Mirror Chart

A mirror chart lets you compare codes frequencies across two questions using similar codebooks; similar means either shared codebooks or codebooks that contain codes with the same wording.

To create a mirror chart, add a visualization box to a canvas, select a question, and then select Mirror Chart from the visualization type drop-drown. Next, select a comparison question from the Mirror Question drop-down in the options area.

You cannot create mirror charts for illustrations created from inspections.

![](https://static.goascribe.com/Help/Create_a_mirror_chart.gif)

The mirror chart options are not always visible. To see them, click the chart. The chart frame darkens, which indicates that it is selected, and the options display on the right side of the screen. Here are the mirror chart options:
