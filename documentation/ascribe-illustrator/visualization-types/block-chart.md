# Block Chart

In a block chart, each code is represented by a rectangle whose surface is proportional to the code's frequency.

To create a block chart, add a visualization box to a canvas, select a question, and then select Block Chart from the visualization type drop-drown.

![](https://static.goascribe.com/Help/Create_a_block_chart.gif)

The block chart options are not always visible. To see them, click the chart. The chart frame darkens, which indicates that it is selected, and the options display on the right side of the screen. Here are the block chart options:
