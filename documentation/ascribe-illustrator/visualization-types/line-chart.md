# Line Chart

To create a line chart, add a visualization box to a canvas, select a question, and then select Line Chart from the visualization type drop-drown.

![](https://static.goascribe.com/Help/Create_a_line_chart.gif)

The line chart options are not always visible. To see them, click the chart. The chart frame darkens, which indicates that it is selected, and the options display on the right side of the screen. Here are the line chart options:
