# Analysis Report

This dialog allows you to generate a set of reports for one or more analyses.

The [Analysis Report setting](tools.md#inspections) in the Inspections tab of the Tools dialog determines which reports are created.

For non-sentiment analyses, this report is always created, in addition to the ones selected in the Tools dialog: TR (which contain cross-tabs for topics and responses.)

To delete an analysis report, select the report and then click Delete.

Once an analysis report has been created, you can choose whether you want to display the reports with the filter box in the gray toolbar. Use the drop-down arrow to choose which reports display.
