# Undo and Redo

You can undo or redo up to 25 consecutive actions across all canvases.

* **Supported Actions**: Adding, modifying, or deleting canvases and visualizations (including batch changes).
* **Ignored Actions**: Selecting visualizations (since no changes are made).
* **Navigation**: If an undone or redone action occurred on a different canvas, the application automatically navigates you to that canvas.
