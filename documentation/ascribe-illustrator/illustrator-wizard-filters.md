# Illustrator Wizard - Filters

On this tab, you select any filters you want to apply. Here are the options:

<table><thead><tr><th width="229.333251953125" valign="top">Option</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top">Filters</td><td valign="top"><p>Typically, closed end questions are used as filters. These are listed first. The open end questions are hidden; click Show Open Questions to display those questions.</p><p> </p><p>After you select a question, the codes within the question display. Select the filter criteria.</p><p> </p><p>If you select Apply to Visualizations, the visuals are filtered. If this option is not selected, the filter is applied to the canvas, and any visual added to that canvas is also filtered.</p><p> </p><p>When creating a grid across studies, only the closed ends from the original study is available as a filter.</p></td></tr><tr><td valign="top"><strong>Options</strong></td><td valign="top"></td></tr><tr><td valign="top">Combine Filters</td><td valign="top"><p><strong>No -</strong> When multiple filters are used, separate visuals are created for each filter.</p><p><strong>Or -</strong> When multiple filters are used, the visuals display data that meet any of the filters.</p><p><strong>And -</strong> When multiple filters are used, the visuals display data that meet all of the filters.</p></td></tr><tr><td valign="top">Add Unfiltered</td><td valign="top">A unfiltered visual is added for each visualization type.</td></tr><tr><td valign="top">Apply To Visualizations</td><td valign="top">The visuals are filtered, not the canvas.</td></tr></tbody></table>
