# Batch Illustrations

![](https://static.goascribe.com/Help/batch_visualizations.gif)

You can generate many visualizations at once by clicking the Batch Visualizations button in the toolbar. This dialog displays, where you can select the questions and visualization types.

Here is an example of the Batch Visualizations dialog for illustrations created from a study:

![](https://static.goascribe.com/Help/Batch_visualizations_dialog.gif)

The dialog has these options:

<table><thead><tr><th width="230.6666259765625" valign="top">Option</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top">Questions</td><td valign="top"><p>Select the questions to be represented in the visualizations. Use the check box in the column header to select all questions or click individual questions.</p><p> </p><p>Note that illustrations created from inspections have standard questions available, along with any closed ends/variables.</p><p> </p><p>The standard questions are: Topics, Expressions, Extracts, Topic Comments, Sentiments, Combined Sentiments, Grouped Topics, TEE Hierarchy, Concepts, Concept Comments, and Grouped Concepts.</p><p> </p><p>If analysis hasn't been run on sentiment, then the related questions are not available; if analysis hasn't been run on concepts, then those related questions are not available.</p></td></tr><tr><td valign="top">Visualization Types</td><td valign="top">Select the visualizations to be drawn. Use the check box in the column header to select all visualizations or click individual visualizations.</td></tr><tr><td valign="top">Width &#x26; Height</td><td valign="top">Use the default numbers or change the sizes of the visualizations.</td></tr><tr><td valign="top">Distribution Question</td><td valign="top">Optional: select a question and then select codes within that question to act as a filter. For example, if the Gender closed end is selected and the code "Female" is selected, visualizations would be filtered by "Female".</td></tr></tbody></table>

The One Per Canvas check boxes control how the visualizations are organized:
