# Longitudinal Analysis

Longitudinal analysis allows users to visualize the evolution of specific codes or nets across time. To create the visualization, click the Longitudinal Analysis icon in the toolbar.

![](https://static.goascribe.com/Help/Longitudinal_analysis_icon.gif)

A dialog opens with these options:

<table><thead><tr><th width="238.6666259765625" align="center" valign="top">Option</th><th valign="top">Description</th></tr></thead><tbody><tr><td align="center" valign="top">Control Question</td><td valign="top">Select the question to be used as the time variable. You can also use the Dimensions option to create your own time variable and use the Codebook Editing option to restrict codes.</td></tr><tr><td align="center" valign="top"><p><img src="https://static.goascribe.com/Help/codebook_editing_icon_small.gif" alt=""></p><p>Codebook Editing</p></td><td valign="top">Opens the <a href="codebook-editing.md">Codebook Editing dialog</a> where you can make changes to the codebook display.</td></tr><tr><td align="center" valign="top"><p><img src="https://static.goascribe.com/Help/dimensions_icon_small.gif" alt=""></p><p>Dimensions</p></td><td valign="top">Opens the <a href="dimensions.md">Dimensions Manager dialog</a> where you can create your own question from existing questions.</td></tr><tr><td align="center" valign="top">Width &#x26; Height</td><td valign="top">Use the default numbers or change the sizes of the visualizations.</td></tr><tr><td align="center" valign="top">Display Analysis Question Name</td><td valign="top">Use the analysis question in the chart title.</td></tr><tr><td align="center" valign="top">Visualization Types</td><td valign="top">Select the visualizations to be drawn. Use the check box in the column header to select all visualizations or click individual visualizations.</td></tr><tr><td align="center" valign="top">Analysis Question</td><td valign="top">Select a question and then select codes within that question to display in the visualization.</td></tr></tbody></table>

The One Per Canvas check boxes control how the visualizations are organized:

<table><thead><tr><th width="184.33331298828125" valign="top">Option</th><th valign="top">Visualization Types/ One Per Canvas Not Selected</th><th valign="top">Visualization Types/ One Per Canvas Selected</th></tr></thead><tbody><tr><td valign="top"><p>Analysis Question/</p><p>One Per Canvas Selected</p></td><td valign="top"><ul><li>Creates one canvas</li><li>Creates one of each selected visualization</li><li>Each visualization contains all of the selected codes</li></ul></td><td valign="top"><ul><li>Creates a canvas for each selected visualization</li><li>Each visualization contains all of the selected codes</li></ul></td></tr><tr><td valign="top"><p>Analysis Question/</p><p>One Per Chart Selected</p></td><td valign="top"><ul><li>Creates one canvas</li><li>Creates a visualization for each selected code</li><li>Each visualization contains the information for just one code</li></ul><p> </p></td><td valign="top"><ul><li>Creates a canvas for each selected visualization</li><li>Each visualization contains the information for just one code</li></ul><p> </p></td></tr><tr><td valign="top"><p>Analysis Question/</p><p>Neither Option Selected</p></td><td valign="top"><ul><li>Creates one canvas</li><li>Creates one of each selected visualization</li><li>Each visualization contains all of the selected codes</li></ul></td><td valign="top"><ul><li>Creates a canvas for each selected visualization</li><li>Each visualization contains all of the selected codes</li></ul></td></tr></tbody></table>

Make your selections and click OK to create the visualizations.
