# Fit Visualizations to Canvas

![](https://static.goascribe.com/Help/Fit_visualizations_to_canvas.gif)

This option resizes visualizations based on the current screen resolution; it spaces the visualizations on the canvas according to how large each visualization is and how much room there is on the canvas.
