# Ascribe Illustrator

Ascribe Illustrator allows users to visualize, summarize, and analyze coded data. It is an interactive research analytics and diagnostic tool that can transform data into insights via a wide array of graphic visuals, from simple charts to complex word clouds. The emphasis is on ease of use, efficiency, exports, reuse, and interactivity.

<figure><img src="../../.gitbook/assets/image (316).png" alt=""><figcaption></figcaption></figure>

With Illustrator, you create illustrations of coded data found in study questions or in inspections. An illustration has one or more canvases; the canvases are the "pages" of the illustration, like the worksheets in Excel. You add the visualizations to a canvas. You can manipulate the visualizations, export them for use in other forms, and save them for further changes.

## Navigation

There are several ways to access Illustrator:

* Use the navigation menu
* Click the Illustrator icon on the Home page
* Right-click a study on the Studies page and select Illustrator
* Create an illustration from Inspector.

## Illustrations Dialog

When you navigate to Illustrator, the Illustrations dialog displays. The dialog has several tabs, depending on how you navigated there.

If you navigate from a study on the Studies page or are creating an illustration from an analysis, the dialog has two tabs: Illustrations and New Illustrations.

If you navigate from the navigation menu or by clicking the Illustrator icon on the Home page, the dialog has tabs for Recent Illustrations, Illustrations, Studies, and Inspections (if Inspector is available on the account).

If you are navigating from an inspection with an existing illustration, the illustration itself opens, and the Illustrations dialog does not display.

The Recent Illustrations lists illustrations that you recently used; the number of illustrations that display are dependent on the Number of Recent Illustrations Suggestion option found in the Illustration Tools dialog. The Illustrations tab lists all of your illustrations and any public illustrations on the account.

## Open an Existing Illustration

If you want to open an existing illustration, locate the illustration on the Recent Illustrations tab or the Illustrations tab and double-click it.

## Create an Illustration from a Study

In order to be used in Illustrator, the study questions must have the Cross-Tab task selected. (If you don't want to use a certain question in the illustration, don't have the Cross-Tab task selected for that question.)

To create a new illustration from a study, click the Studies tab, select a study, and click Open. Then click the New Illustration tab. Enter a unique ID and an optional label; click Ok to create the illustration.

A dialog display which confirms the illustration was created and indicates how long it took to create it; click OK to close the dialog.

After you create the illustration, add a visualization by selecting a question and a visualization type. From that point, you can modify the visualization or add more. See [Add Visualization](add-visualization.md) for more information.

You can also create an illustration from a study using the Studies page. Right-click a study and select Illustrator.&#x20;

## Create an Illustration from Multiple Studies

In the Illustrations dialog, click the Studies tab, select the studies you want to use, and click Open. The New Illustration tab displays; enter a unique ID and an optional label. There is one other option:

When you create an illustration from multiple studies, a Studies question is added to the Question list. The Studies question can be used for filtering or as a banner or distribution question; it is treated as a closed end.

You cannot create an illustration from multiple studies from the right-click menu option on the Studies page.

Note there are two options involving multiple studies. The second option is to create a grid across studies. Questions must be shared across studies. The [grid across studies](illustrator-wizard.md#visualizations) is either created with the Wizard or by selecting the [Multi-Studies](visualization-types/grid.md) option in the grid properties pane.

## Create an Illustration from an Inspection

To create an illustration from an inspection, use Load Inspection to Illustration. &#x20;

Or you can use the Inspections tab of the Illustrations dialog to find the inspection and create a new illustration.&#x20;

After you create the illustration, add a visualization by selecting a question and a visualization type. From that point, you can modify the visualization or add more. See [Add Visualization](add-visualization.md) for more information.

## Hide or Delete Illustrations

The Illustrations tab has an option to hide or delete illustrations.

Hiding an illustration removes the illustration temporarily from the list of illustrations on the Illustrations tab and the Recent Illustrations. The hidden illustrations can be displayed again. To hide an illustration, select it and click Hide. To display it again, click Include Hidden Illustrations. The illustrations display in blue.&#x20;

Deleting an illustration removes the illustration permanently. The Recent Illustrations tab and the Illustrations tab both have the delete option.  To delete an illustration, select it and click Delete.
