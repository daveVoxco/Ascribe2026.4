# Illustrator Wizard - Questions

The second step for creating visualizations is to select the questions you want to view. After you select a question or questions, click Next to open the Filters tab or click Finish to generate the visualizations.

Here are the options:

<table><thead><tr><th width="238.66668701171875" valign="top">Option</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top">Filter Box</td><td valign="top">The text field acts as a filter for the list of questions; it does not affect the list of question in the Banners section. Enter character string found in question ID to display the question or questions.</td></tr><tr><td valign="top"><p>Question Type /</p><p>Coded Questions Only</p></td><td valign="top"><p>Select the type of questions to display in list of questions.</p><p> </p><p>Click the checkbox to display only the questions that are coded.</p></td></tr><tr><td valign="top"><p>Questions</p><p> </p></td><td valign="top">Select the questions you wish to view. Closed end questions have brackets around their ID.  </td></tr><tr><td valign="top">Banners</td><td valign="top"><p>Typically, closed end questions are used as banners. These are listed first. The open end questions are hidden; click Show Open Questions to display those questions.</p><p> </p><p>This option is not available for Grids Across Studies.</p></td></tr></tbody></table>

If you selected Grid Across Studies on the Visualizations tab of the Wizard, the shared questions for each study automatically display on the Questions tab.
