# Slideshow Mode

![](https://static.goascribe.com/Help/Slideshow_Mode.gif)

You can display all of the visualizations on a canvas in slideshow (full screen) mode by clicking the Slideshow button in the gray toolbar or on the visualization.

When in slideshow mode, these controls display:

![](https://static.goascribe.com/Help/Slideshow_Mode_Options.gif)

Use the Resize button in the gray toolbar or on the visualization to return the visualization to previous size.

Use the arrow control buttons to page through the visualizations.

The progress bar indicates where you are in the slideshow.
