# Add Objects

![](https://static.goascribe.com/Help/Add_objects.gif)

You can add additional information to a canvas through these options: [Add Text](add-objects.md#add-text), [Add Icon](add-objects.md#add-icon), [Add Filter Info](add-objects.md#add-filter-info), and [Add Table of Contents](add-objects.md#add-table-of-contents).

## Add Text

To add text to the canvas, click the Add Text button in the gray toolbar. Three dots display on the canvas, and the visualization type changes to Other. The options display on the right side of the screen:

<table><thead><tr><th width="225.99993896484375" valign="top">Option</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top">Fixed Visualization</td><td valign="top">When selected, the visualization cannot be moved on the canvas.</td></tr><tr><td valign="top">Font Size</td><td valign="top">Font size of text; maximum is 35.</td></tr><tr><td valign="top">Font Choices</td><td valign="top">Select from bold, italic, and underline; if none are selected, the regular font is used.</td></tr><tr><td valign="top">Color</td><td valign="top"><p>To choose color:</p><ul><li>Select color from the color gradient square</li><li>Select color from the color spectrum bar</li><li>Enter RGB numbers in this format: rgb(N,N,N)</li><li>Enter hex codes</li><li>Enter color names supported by all browsers.</li></ul><p>For hex codes and color names, see <a href="http://www.w3schools.com/colors/colors_names.asp">http://www.w3schools.com/colors/colors_names.asp</a> .</p><p>After you select a color, click the Choose button to apply it to the visualization.</p></td></tr><tr><td valign="top">Text</td><td valign="top">Enter text to display on the canvas</td></tr><tr><td valign="top">Target Canvas</td><td valign="top">Create a hyperlink to another canvas by selecting a canvas in the drop-down list; when you click on hyperlinked text, it takes you to the target canvas.</td></tr></tbody></table>

The text can be moved with the mouse or resized with the resizer handle.

To remove text from the canvas, click it and then the Delete button on the gray toolbar.

## Add Icon

To add a logo or image to the canvas, click the Add Icon button in the gray toolbar. The initial logo created may be the Ascribe logo. The visualization type changes to Other. You can change the logo through the options on the right side of the screen:

<table><thead><tr><th width="236" valign="top">Option</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top">Fixed Visualization</td><td valign="top">When selected, the visualization cannot be moved on the canvas.</td></tr><tr><td valign="top">Choose File</td><td valign="top">Click this button to browse to your computer and choose another image file. The file should be approximately 500 KB or less.</td></tr></tbody></table>

The image can be moved with the mouse or resized with the resizer handle.

To remove an image from the canvas, click it and then the Delete button on the gray toolbar.

## Add Filter Info

To add filter information to the canvas, click the Add Filter Info button in the gray toolbar. If the visualization is not filtered, only the three dots display. The visualization type changes to Other. Once a filter is active, the information displays. You can the color and font through the options on the right side of the screen:

## Add Table of Contents

To add a table of contents, click the Table of Contents button on the gray toolbar. The confirmation dialog has options for the table of contents to be placed on the first canvas, a new canvas, or the current canvas.&#x20;

The canvas names on the table of contents are hyperlinked to the corresponding canvases.

To delete a table of contents from a canvas, click Select All Visualizations and then click Delete. Note, if you have other visualizations on the canvas that you don't want to delete, unselect them before clicking Delete.
