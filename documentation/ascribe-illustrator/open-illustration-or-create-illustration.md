# Open Illustration or Create Illustration

![](https://static.goascribe.com/Help/Open_or_New_button_on_toolbar.gif)

The Open/New button opens the Illustrations dialog, which allows you to access an existing illustration or create a new illustration. See [Illustrations dialog](open-illustration-or-create-illustration.md) for more information.

When you create an illustration, the screen displays a blank Canvas 1. The next step is to [add a visualization](add-visualization.md), select a question, and visualization type.&#x20;

Canvas 1 cannot be deleted. However, if you want to move the contents of Canvas 1 to another canvas, use the [Duplicate Canvas](add-or-copy-canvas.md) option.
