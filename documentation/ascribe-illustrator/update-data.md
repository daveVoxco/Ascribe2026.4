# Update Data

![](https://static.goascribe.com/Help/Update_Data.gif)

The Update Data option allows you to add new data to the illustration from the study or inspection. For example, if you add data to a study question or add a question to the study, you may want the illustration to reflect those changes. Before you use update data, you might want copy the illustration so you have a backup.

When you click Update Data, you may be prompted to save the current illustration. If so, click OK. Next, you are prompted to confirm the update. Click OK to continue.

A dialog then displays with a list of studies and inspections. Locate your study or inspection, click it, and then click Open. The new data is now available to the illustration.

You can also use this option to change to a different study or inspection; when the dialog displays with the list of studies and inspections, you can select any study or inspection. If you change studies or inspections, first use the Save As option and save the current illustration with a different name.
