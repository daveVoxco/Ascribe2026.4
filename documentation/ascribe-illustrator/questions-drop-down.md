# Questions Drop-Down

![](https://static.goascribe.com/Help/Create_visualization.gif)

To create a visualization, click the Add Visualization button in the gray toolbar, select a question from the Question drop-down list, and then select a visualization type from the Visualization Types drop-down list.

Close-ended questions display with brackets around them.

Questions created through the [Dimensions](dimensions.md) option have parentheses around them.

If an illustration was created from multiple studies, a Studies question is available in the question list. The Studies question contains the study name and number of respondents in the study. It can be used for filtering or as a banner or distribution question.
