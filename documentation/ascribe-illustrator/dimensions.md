# Dimensions

![](https://static.goascribe.com/Help/Dimensions.gif)

You can create your own dimensions or virtual questions by adding and/or combining codes together. These questions can be used in most visualizations (not correlation matrix, word clouds, grid, and verbatim.) Questions created this way display with parentheses around them in the Questions drop-down list.

The Dimensions Manager dialog has two tabs: Questions and Dates. Click the Dimensions button in the toolbar to display this dialog:

![](https://static.goascribe.com/Help/Dimensions_manager_dialog.gif)

## Create a Dimension Question

Select a question from the question drop-down, and then select one or more codes. Click the forward arrow to add the selected code(s) to the new dimension. You can include codes from different questions in the list; just select another question and move the codes to the right pane.

Note that if you choose to add a net as a dimension, it is created as a code.&#x20;

If you would like to include the question ID in front of the code, click the Specify Question Name check box.

Once you have all of the necessary codes in the right pane, enter a name in the Dimension Name box and click OK.

To remove codes from the dimension, click the code and then click the backward arrow.

To combine the selected codes into one new code, click the codes, click the middle button, and enter a name in the dialog that displays.

## Edit an Existing Dimension Question

To edit an existing dimension question, display the dimension on the left side of the dialog using the drop-down list. This action displays the fields currently in the dimension.

On the right side of the dialog, enter existing dimension in the Dimension Name field.&#x20;

From the left side, move to the right side any of the existing fields that you want to keep. Then use the question drop-down on the left to select a question and select additional codes to add to the dimension.
