# Exports

![](https://static.goascribe.com/Help/Exports_for_illustrations.gif)

When one or more visualization is selected, the export options are enabled.

<table><thead><tr><th width="180.66668701171875" valign="top">Option</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top">Excel</td><td valign="top">All tables (cross-tab, grids, verbatim lists) can be exported to Excel. For charts, the underlying data can be exported to Excel.</td></tr><tr><td valign="top">PowerPoint</td><td valign="top">Only charts can be exported to PowerPoint.</td></tr><tr><td valign="top">Zip File</td><td valign="top">If a chart or charts are selected, creates a zip file containing PNG images of the charts. If a combination of table/tables and chart/charts are selected, creates a zip file containing one Excel file for the tables and one PowerPoint file for the charts.</td></tr><tr><td valign="top">SVG File</td><td valign="top">Creates a scalable vector graphics file of the selected chart. SVG files can be edited using an SVG editor and then saved to PowerPoint.</td></tr><tr><td valign="top">HTML</td><td valign="top">Selected visualizations can be exported to a static HTML image.</td></tr></tbody></table>

Charts can be copied to the clipboard. A miniature image displays; right-click it and select the appropriate menu item.
