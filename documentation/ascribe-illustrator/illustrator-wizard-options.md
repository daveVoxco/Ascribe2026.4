# Illustrator Wizard - Options

This section allows you to customize the visualizations. One section applies to all visualizations, and the other sections are specific to the visualizations you chose in the first tab of the Wizard.

The sections are: All Visualizations, Cross-Tab, Grid, Prop. Code Fonts, Verbatim, Bar Chart, Line Chart, Pie Chart, Block Chart, Word Cloud, Code Cloud, Co-occurrence Chart, Correlation Matrix, Hi Block Chart, Star Plots, and Correspondence Analysis.

Once you select options, click Finish to generate the illustrations.&#x20;
