## Links

Users can create links to illustrations. This option provides access to illustrations for users who do not have a login ID for the Ascribe account. It can also be used if you want to send a read-only view of the illustration to someone. (If someone has a login ID to the Ascribe account, they can access public illustrations through the Open/Create Illustrations screen. You don't need to send them a link.)

An illustration must be saved in order to create links. The Links tab will not display unless the illustration has been saved.

The links contain a URL (a web address) and a password, which can be emailed. The illustration must be [public](tools.md#options) in order for the user to access the illustration. When the user clicks the URL, the user is directed to the website and asked to enter the password. The appropriate illustration opens in read-only mode; the user can filter the visualizations by clicking on items, but the illustrations cannot be saved or exported. The user cannot navigate anyplace else in Ascribe. The user can add and save notes, which are then available to any user viewing the illustration.
