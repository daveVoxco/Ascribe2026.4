# Sample Size

![](https://static.goascribe.com/Help/Sample_Size.gif)

The sample size is the number of unique respondents in the study or inspection. When you use filters, the sample size changes to reflect the filter, and the background color will be yellow. The color change is a visual indication that you are filtering.

If you click the sample size, a dialog displays a list of the respondent IDs.

For illustrations created from inspections, the number of respondents is from all analyses in the illustration; if you have more than one analysis in the illustration, the total respondents is based on all analyses. Your visualizations can be based on just the respondents from one analysis by using the Base = Total Coded or Base = Total Gave Answer options on the individual visualizations.&#x20;

For illustrations created from multiple studies, see [Treat Duplicate Respondent IDs as Unique](./#create-an-illustration-from-multiple-studies) for more information.
