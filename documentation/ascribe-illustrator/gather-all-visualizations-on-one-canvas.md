# Gather All Visualizations on One Canvas

![](https://static.goascribe.com/Help/Gather_all_visualizations.gif)

This option allows you to put all visualizations on one canvas, which is titled All Visualizations. It is helpful when you need to export all of the visualizations. Once all of the visualizations are on one canvas, you can select all and then choose your export.

Every time you use the Gather option, a new All Visualizations canvas is added.
