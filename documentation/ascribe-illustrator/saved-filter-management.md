# Saved Filter Management

![](https://static.goascribe.com/Help/Saved_Filter_Management.gif)

You can save a filter and reuse it. To save the currently active filter, click the Save Filter button in the toolbar. A dialog displays; enter a name and click OK. The canvas clears when you save a filter. To reapply the filter, use the drop-down List of Saved Filters.

## Apply Filter to Current Canvas

To permanently apply a filter to a canvas, open the canvas, select a filter from the List of Saved Filters, and click the Apply Filter to Current Canvas.

The canvas name changes to the filter name, and visualizations have the filter applied.

## Apply Filter to Selected Visualizations

To apply a filter to selected visualizations, select visualizations, select a filter from the List of Saved Filters, and click the Apply Filter to Selected Visualization button.

The visualizations will display with red brackets next to the question ID. The visualizations are saved with the filter applied.

To remove the filter, click the Remove Visualization Filters button in the visualization's Option area.

## Delete Filter

To delete a saved filter, select it in the List of Saved Filters, and click the Delete Filter button in the toolbar.

## Filters Dimension in Question List

When you create saved filters, they automatically appear in a special dimension called \[Filters Dimension] in the Question List. This dimension can be used as a question in visualization types like cross-tab, bar chart, and line chart.
