# Codebook Editing

![](https://static.goascribe.com/Help/Codebook_editing.gif)

This dialog allows you to make some changes to items in the visualizations such as codes, groups, or ungrouped items. The dialog has three tabs: [Codes to Ignore](codebook-editing.md#codes-to-ignore), [Code Colors](codebook-editing.md#code-colors), and [Codes Not To Sort](codebook-editing.md#codes-not-to-sort) (studies only).

## Codes to Ignore

To ignore specific codes in the visualizations, use the Codes to Ignore tab. A dialog displays with the following options:

<table><thead><tr><th width="266.6666259765625" valign="top">Option</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top"><p>Apply To All Shared Questions</p><p>(Studies Only)</p></td><td valign="top">Codes are ignored in all shared questions.</td></tr><tr><td valign="top"><p>Apply To Net Children</p><p>(Studies Only)</p></td><td valign="top">If you click a net, all children (codes) in the net are ignored.</td></tr><tr><td valign="top">Question List</td><td valign="top"><p>Select a question from the drop-down list and click any code/item to ignore it.</p><p> </p><p>To view the ignored codes/items, select "All Ignored Codes" in the drop-down. You can unselect ignored codes/items by clicking them.</p></td></tr></tbody></table>

## Code Colors

This option works in conjunction with the Apply Code Colors. In order to change the code colors, Apply Code Colors must be selected.

Use this option to choose the color of specific codes, nets or topics.

<table><thead><tr><th width="226.66668701171875" valign="top">Option</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top">Color Selection</td><td valign="top"><p>First, select a question from the Question List drop-down and click any code/net to select it. Then choose the color.</p><p>There are several ways to choose a color:</p><ul><li>Click one of the 9 default colors in the small squares on the left side of the dialog; the dialog closes, and the color is applied to the code.</li><li>Select a color from the color spectrum bar, which populates the color gradient square; click in the square and then click Choose to apply it.</li><li>You can enter an RBG code in the text box and click Choose to apply it to the selected items.</li><li>The color selection remembers the last color used in the current session.</li></ul></td></tr><tr><td valign="top"><p>Apply To Net Children</p><p>(Studies Only)</p></td><td valign="top">Applies color to all members of a net.</td></tr><tr><td valign="top">Default Code Color</td><td valign="top">When selected, applies the Default Code Color to all codes of all visualizations; you can override the default code color with Apply Code Colors. The Color Selection box works as mentioned above.</td></tr><tr><td valign="top">Apply Code Colors</td><td valign="top">Use the codes' colors in the visualizations; it uses the code colors from the originating question in a study or colors selected in the Code Colors dialog. This setting overrides the Color Palette option in block charts, code clouds, and word clouds. For example, if you select a color for a code in this dialog, the code will have that color regardless of the color palette selected for block charts, code clouds, and word clouds.</td></tr><tr><td valign="top">Question List</td><td valign="top"><p>Select a question from the drop-down list and click any code/net to select it. Use the check box next to Codes to select or deselect all codes and nets.</p><p>You can unselect codes/nets individually by clicking them.</p></td></tr></tbody></table>

Code Colors affects the codes in cross-tab, bar chart, line chart (points on the line), pie chart, block chart, code cloud, co-occurrence chart, mirror chart, hi-block cart, and grid.

## Codes Not To Sort

This option is for studies only. To exclude specific codes when sorting the data in visualizations, use the Codes not to Sort tab. A dialog displays with the following option:

<table><thead><tr><th width="174.6666259765625" valign="top">Option</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top">Question List</td><td valign="top"><p>Select a question from the drop-down list and click any code/item in order not to have it sorted with the other items in the visualization. If you select a code that is part of a net, the code will be at the bottom of the net; it cannot be moved outside the net.</p><p> </p><p>You can unselect codes/items by clicking them.</p></td></tr></tbody></table>
