# Add or Copy Canvas

![](https://static.goascribe.com/Help/Add_or_Copy_Canvas.gif)

You can add multiple canvases to the illustration. Click the Add Canvas button, and another canvas displays. It is automatically given the name 'Canvas N', where N equals the next numeric value available. You can change the canvas name in the Canvas Options dialog.

To copy a canvas, click the Duplicate Canvas button. The copied canvas is named 'Copy of' whatever the original canvas was named. You can change the canvas name in the [Canvas Options](canvas-options.md) dialog or by double-clicking on the canvas.

To delete a canvas, click the X in the top right corner of the canvas tab.

Canvas 1 cannot be deleted or reordered, but it can be renamed.

Canvases can be reordered by click/dragging their tab headings.

Once you add a canvas, click the Add Visualization button to start creating visualizations.
