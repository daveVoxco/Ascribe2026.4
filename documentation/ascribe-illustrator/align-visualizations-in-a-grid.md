# Align Visualizations in a Grid

![](https://static.goascribe.com/Help/Align_as_Grid_june_30.gif)

When you have multiple visualizations on a canvas, you can organize them in a grid with the Grid button. Their sizes will be equal to the size of the last selected visualization. Visualizations that are marked as 'Fixed' will be ignored.
