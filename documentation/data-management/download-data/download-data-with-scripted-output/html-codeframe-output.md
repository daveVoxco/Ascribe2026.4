# HTML Codeframe Output

_Navigate: Client/Studies/Right-click study/Select Download Data/Select Scripted Output/Select HTML Codeframe_\
_Supervisor/Studies/Right-click study/Select Download Data/Select Scripted Output/Select HTML Codeframe_

This script displays the code input and output values and textual descriptions as well as counts and percentages. The count of respondents represents an unduplicated net count.
