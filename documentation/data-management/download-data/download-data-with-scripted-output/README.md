# Download Data with Scripted Output

_Navigate: Client/Studies/Right-click a study/Select Download Data/Select Scripted Output_\
_Supervisor/Studies/Right-click a study/Select Download Data/Select Scripted Output_

Scripted output provides very flexible custom output files to generate data and reports that are not already available in Ascribe. By default, every account has at least 5 outputs available. Ascribe has the ability to create custom output files using a scripting language. This allows Ascribe to create very flexible custom output in virtually many formats. Scripted output is available from the Client/Download data menu.

You have the ability to run output scripts, but you cannot create or modify them. Support can create custom scripts to suit your needs. [Contact Support](https://app.gitbook.com/s/z7SRTUu0F0liQ4Zr5Bdl/contact-support-ascribe) to request a custom output script.

The Scripted Output page lists the Study ID, study name, and number of questions in a table at the top of the page. The Study ID has a drop-down box which contains information about the study. The Questions field has a drop-down box which lists the questions in this study.

There are drop-down boxes for the Question ID, Codebook ID, and Shared Codebook columns which give more information about these fields.

Next to the script drop-down box is a check box for Export in Text format. Uncheck this box if you want the result in Excel.

To execute a scripted output, select the desired program from the drop-down menu and check the questions you wish to include. The following reports will be available by default:

* [Auto-Coder Script](auto-coder-script.md)– Auto-codes exact textual matches or creates the coding consistency report
* [Column Binary Output Script](column-binary-output-script.md) – Tabulation Data
* [Excel Data Output](excel-data-output.md) –Data in Excel format
* [Excel Horizontal Verbatims](excel-horizontal-verbatims.md) – Output with RID in first column and QID’s in first row
* [HTML Codeframe Output](html-codeframe-output.md) – Marginal Report in HTML format
* [HTML Data Layout](html-data-layout.md) – Data Map as laid out in Ascribe
* [Marginal CSV Report](marginal-csv-report.md) (duplicated nets) – Same as HTML Codeframe only net counts are not unduplicated and the format is . csv rather than HTML
* [Max Codes Report](max-codes-report.md) – reports those respondents that have more codes assigned than the max code setting allows (see max codes under question setup)
* [SAV File Export](sav-file-export.md) – Creates a SAV file for loading into SPSS and/or Dimensions
* [Translation Consistency Report](translation-consistency-report.md) – Reports inconsistencies in translations of duplicate verbatims
