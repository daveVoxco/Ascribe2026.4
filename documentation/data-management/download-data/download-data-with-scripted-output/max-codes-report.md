# Max Codes Report

_Navigate: Client/Studies/Right-click study/Select Download Data/Select Scripted Output/Select Max Codes Report_\
_Supervisor/Studies/Right-click study/Select Download Data/Select Scripted Output/Select Max Codes Report_

This script creates and HTML document that details any respondent that has more codes applied than allowed by the Max Codes property for each question.
