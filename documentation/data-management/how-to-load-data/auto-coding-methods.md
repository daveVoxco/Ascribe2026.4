# Auto-Coding Methods

Ascribe has several methods for automatically applying codes:

* Auto-code while loading data: [Load Data to a Study](load-data-to-a-study.md).
* Auto-code responses in shared questions with a script after data has been loaded: [Auto-Coder Script](../download-data/download-data-with-scripted-output/auto-coder-script.md)
* Auto-code closed-ends or other specify responses: [Auto-Code Responses](../../verbatims/auto-code-closed-ends-and-other-specify-responses.md)
