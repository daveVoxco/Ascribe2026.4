# Loads by Date

_Navigate: Supervisor/Loads_

The Loads by Date table shows the result of a specific file load attempt. There is one row for each load attempt for the date ranged specified. The default view is to show load activity for the past seven days. To view a different date range, select date choices from the drop-down boxes and click the OK button.

The displayed list includes the following columns:

<table><thead><tr><th width="222.6666259765625" valign="top">Column</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top">Study ID</td><td valign="top">The study ID.</td></tr><tr><td valign="top">Load Date</td><td valign="top">Date and time of the load.</td></tr><tr><td valign="top">Load File</td><td valign="top">Name of the file loaded.</td></tr><tr><td valign="top">Responses Loaded</td><td valign="top">Number of records loaded in total or the word "Error" if an error occurred.</td></tr><tr><td valign="top">Comment</td><td valign="top">This column is blank for successful loads or contains the error description if the load was unsuccessful.</td></tr></tbody></table>

To view details of the loaded file, right-click a table entry and select Load Details. The [Load Details](load-details.md) page will display.

To delete a load, right-click a table entry and select Delete. This action will delete all responses in all questions which were loaded from the file on the date and time indicated.
