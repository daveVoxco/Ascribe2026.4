# Loads by Job

_Navigate: Jobs/Right-click a job/Select Loads_

This table displays each of the loads performed by the job. In many cases, there will be only one load per job, as is normal when a single file is submitted for the job. If the file submitted for the job is a zip file, there can be many loads performed by a single job.

Here are the fields on this screen:

<table><thead><tr><th width="215.333251953125" valign="top">Field</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top">Study ID</td><td valign="top">The ID of the study to which the responses were loaded.</td></tr><tr><td valign="top">Load Date</td><td valign="top">The date and time the load was performed.</td></tr><tr><td valign="top">Load File</td><td valign="top">The name of the file loaded.</td></tr><tr><td valign="top">Responses Loaded</td><td valign="top">If the load was successful, this entry shows the name of responses loaded. If unsuccessful, this entry displays an error message.</td></tr><tr><td valign="top">Comment</td><td valign="top">This entry may show additional information about the load.</td></tr></tbody></table>

To see more information about the load, right-click the load and select [Load Details](load-details.md).

To delete a load, right-click a load and select Delete. This action will delete all responses in all questions which were loaded from the file on the date and time indicated.
