# Time by Associate, Question, and Activity Within a Study

_Navigate: Administrator/Select Time Accounting/Select Time by Study/Right-click study/Select Time by Associate, Question, Activity_

This report displays time accounting for the study, organized by associate, then by question, and then by activity.&#x20;

## Time Tracking Additional Information

When coding shared codebooks, time is always tracked to the first question displayed in the list of questions at the bottom of the page.  This is true even when you are coding across studies.

When coding questions (not a sample), the first question in the list will be the one you navigated from to get to Ascribe Coder.

When coding a sample, the first question in the list is the question in the sample that has the most responses in the sample. The other questions in the list of questions are displayed first by study ID, then by question ordinal, then by question ID.
