# Time Details Within a Study

_Navigate: Administrator/Select Time Accounting/Select Time by Study/Right-click study/Select Time Details_

This report displays all time accounting records for this study.&#x20;

The page is organized like this:

Click the hyperlinked ID to view study details.</td></tr><tr><td align="center" valign="top">Search</td><td valign="top">Use the Search field to filter the page.</td></tr></tbody></table>
