# Time Accounting Reports

Time accounting provides time and cost information about your studies. Only administrators have access to Time Accounting. Ascribe has three types of time accounting reports: Time Current (currently open sessions), Time by Study, and Time by Period. Within the Time by Study and Time by Period reports, there are additional options for more detail.
