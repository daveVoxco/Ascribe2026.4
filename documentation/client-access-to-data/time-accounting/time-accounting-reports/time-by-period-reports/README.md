# Time by Period Reports

The Time by Period reports should be used when you want to look at certain periods of time. For example, you might want to monitor how your coding staff spent their time last month. Time by Period reports can give you this information.

From the initial Time by Associate report, you can select other reports to display the time accounting details across activities and studies.

You can change the time period if you click the Change button at the top of the screen. A dialog box displays, and you can select the dates. Click OK to see the report for those dates.

For reports that show time by study instead of period, use the [Time by Study Reports](../time-by-study-reports/) instead.

The Time by Period and Time by Study reports do not show information for currently open sessions. Use the [Time Current](../time-current.md) report to see information for open sessions.
