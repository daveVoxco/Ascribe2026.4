# Transaction Reports

The following reports are available for cost accounting if you have administrator privilege: Transactions by Period, Transactions by Study, Transactions by Month, Transactions by Month and User, and Transactions by User.

## Transactions by Period <a href="#minitocbookmark2" id="minitocbookmark2"></a>

_Navigate: Administrator/Select Transactions/Select Transactions by Period_

This report shows transactions used during a specific time period. While the format of this report is very similar to the [Transactions by Study](transaction-reports.md#minitocbookmark3) report, the contents of the report are quite different. This report shows all transactions for the specified period (and only transactions that fall in that period.) The [Transactions by Study](transaction-reports.md#minitocbookmark3) report shows all transactions for specific studies, regardless of when the transaction was recorded.

The report shows transactions broken down by the type of the verbatim, with rows for each study. A study will appear in the report only if at least one transaction was recorded for the study in the specified time period. The bottom row of the report shows a total column for all rows.

## Transactions by Study <a href="#minitocbookmark3" id="minitocbookmark3"></a>

_Navigate: Administrator/Select Transactions/Select Transactions by Study_

The format of this report is similar to the [Transactions by Period](transaction-reports.md#minitocbookmark2) report. If a study is included in this report, it will show all transactions for that study, regardless of whether the transaction was applied within the selected time period or not. This message displays as a reminder: Transaction counts = total transactions for a study. Transaction count is irrelevant of the date filter; to filter transaction count by date, use the Transactions by Period report.

**Filter by Date Range or by Study ID/Name**

This report can be filtered by a date range or by study ID and name. (You cannot filter by both the date range and the study ID/name.)

When you select Search by Study ID/Name, the date selector is disabled, and a search box displays. Enter study ID or name to filter the list.&#x20;

**Select Date Range**

When you select Search by Create Date, the option to search by Study ID/Name is disabled.&#x20;

There are two ways to select dates. You can use the drop-down list next to the Use local time box to select today, this week, this month, this year, last week, last month, or last year. When you select one of these options and click Update, the dates change to reflect your selection, and a list of studies displays.

Another way to select dates is select Custom Range. A calendar displays. Use the arrows next to the calendar heading to scroll through the months. Or click the heading to see a list of months. Click the heading a second time to see a list of years. Use the arrows to scroll through the months or years.
