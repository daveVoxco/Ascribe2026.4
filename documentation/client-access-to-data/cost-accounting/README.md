# Cost Accounting

The various cost accounting reports detail your usage of Ascribe transactions. If you have administrator privilege, you can view these reports to understand how you are using your transactions.

The reports include:

* [Fee Schedule](fee-schedule.md)
* [Transactions by Period](transaction-reports.md#minitocbookmark2)
* [Transactions by Study](transaction-reports.md#minitocbookmark3)
* [Account Statement](account-statement.md)
