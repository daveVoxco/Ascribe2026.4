# Study Summary Report (New)

The Study Summary Report displays two tables.&#x20;

* **Study Information**: Shows summary Information about the study..&#x20;
* **Question Type**: Shows a table that lists coding information by question type.

<figure><img src="../../../.gitbook/assets/image (328).png" alt=""><figcaption><p>Study Summary (new)</p></figcaption></figure>

**Location**: Right-click Study > Reports > Study Summary (New)

<table><thead><tr><th width="200.048583984375" valign="top">Field</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top">Study Name</td><td valign="top">The study name</td></tr><tr><td valign="top">Study ID</td><td valign="top">The study identification number</td></tr><tr><td valign="top">Created</td><td valign="top">The date the study was created</td></tr><tr><td valign="top">Start Date</td><td valign="top">The date work on the study was started</td></tr><tr><td valign="top">Description</td><td valign="top">The description of the study from the Study Edit screen</td></tr><tr><td valign="top">Help</td><td valign="top">The information about the study from the Study Edit screen</td></tr><tr><td valign="top">Supervisor</td><td valign="top">The supervisor of the study</td></tr><tr><td valign="top">Client</td><td valign="top">The company that requested the study</td></tr><tr><td valign="top">End Customer</td><td valign="top">The end customer of the study</td></tr><tr><td valign="top">Status</td><td valign="top">The coding status of the study from the Study Edit screen</td></tr><tr><td valign="top">Coders</td><td valign="top">The number of coders who worked on this study</td></tr><tr><td valign="top">Loads</td><td valign="top">The number of successful loads for this study</td></tr><tr><td valign="top">Transactions</td><td valign="top">The number of transactions used on this study; only administrators can view this information</td></tr><tr><td valign="top">Hours</td><td valign="top">The number of hours spent on this study; only administrators can view this information</td></tr></tbody></table>
