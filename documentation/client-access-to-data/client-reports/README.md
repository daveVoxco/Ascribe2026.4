# Client Reports

_Navigate: Supervisor/Studies/Right-click study/Click Reports_

All items in the client results section display in "real time." Information is pulled directly from the database and includes all data/information in the database at the time the report was generated.

{% hint style="info" %}
#### Note

Real-time is a much misused term. Here it means "you are getting the results as they are stored in the database."
{% endhint %}

When you navigate to the Studies page, the list of studies is displayed. You can filter the list by the study status. In the grey bar at the top of the window, check the status boxes for the studies you want to view, and then click the Update button. You also have the option to change the properties of the study if you right-click the study and select Edit.

Ascribe has several client reports available, all of which can be copied to Excel:

* [Coding Overview Report](coding-overview-report.md)
* [Study Summary Report](study-summary-report.md)
* [Question Summary Report](question-summary-report.md)
* [Card Layout Report](card-layout-report.md)
* [Study Report](study-report.md)
* [Study Quality Report](study-quality-report.md)
* [View Codes by Coder Report](view-codes-by-coder-report.md)
* [Respondents Report](respondents-report.md)

{% hint style="info" %}
#### Note

To copy a report to Excel, click the Excel icon which is above the first column in each screen. A window in Excel opens, and the report is copied into the columns.
{% endhint %}
