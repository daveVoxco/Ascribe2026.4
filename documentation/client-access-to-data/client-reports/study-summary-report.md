# Study Summary Report

The Study Summary Report displays two tables. Summary information about the study is at the top of the page. The second table lists coding information by question type.

**Location**: Right-click Study > Reports > Study Summary

{% hint style="success" %}
#### Tips

Use the new summary report for a version with an improved visibility: [study-summary-report-new.md](study-summary-report-new.md "mention")
{% endhint %}
