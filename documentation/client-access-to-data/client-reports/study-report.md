# Study Report

The study report provides a real-time summary of the coding results for each question.

**Location**: Client/Right-click study/Select Reports/Click Study Report

{% hint style="info" %}
#### Note

Real-time is a much misused term. Here it means "you are getting the results as they are stored in the database."
{% endhint %}

Typically this report is used by people who want to monitor progress, assess and approve codebooks, check for quality, and perform audits. It has two basic components: a study summary and a question summary for each question in the study.

### Question Summary within the Study Report <a href="#minitocbookmark3" id="minitocbookmark3"></a>

Each question in the study is listed with summary and detail information. You can click the <img src="https://static.goascribe.com/Help/09_-_Client_Access_to_Data_julie_files/image020.gif" alt="" data-size="line">icon to view the verbatims and codes applied for the question.
