# Client Access to Data

The client section of Ascribe provides controlled access to each study and may be accessed by project directors, clients, tabulators, account executives, etc.

The Client Studies page lists the studies available to you. The studies listed depend on the type of user account you for Ascribe. If you have an [associate](../user-administration/associates.md) account, you can see all of the studies except those that are archived. If you have a [contact](../user-administration/contacts.md) account, you can see only those studies for your company. &#x20;

This chapter details the following types of data available to clients:

* [Client Reports](client-reports/)
* [Cost Accounting](cost-accounting/)
* [Time Accounting](time-accounting/)
