# Trained Codebook Process

Here are suggestions on how to train a codebook to use for tracker studies:

**Train original codebook with manually coded data.**

1. Open question(s) in Ascribe Coder (be sure the coding source reflects all responses needed to train the codebook).
2. Access AI Coder.
3. In the Analyze dialog, choose Train Codebook from Codebook drop-down.
4. Choose to use either Generative or Non-Generative AI.  If using non-generative make sure the split characters and words work for this project. If using generative, decide if you want to use a prompt. Remember this prompt as you will want to use it on future projects where the trained codebook will be applied.
5. Click OK.

**Clean-up segments in AI Coder and save the trained codebook.** (Note: original/ trained codes cannot be changed; all original codes and nets have borders; segments associated with a code can be removed or moved; new codes and/or nets can be added; new codes will not have borders and can be edited/ combined)

1. Optional: Use Auto Code Others to create codes that can be combined into existing codebook.
2. Optional: Check Others for easy to categorize segments and move into appropriate code.
3. Optional: Check segments associated with codes and remove any obscure segments; move any incorrectly classified segments to the proper code.
4. Save the codebook.
5. Once the codebook is saved, it is available to use for coding other projects.

**Use a trained codebook for the next wave of a tracker study.**

1. Set up the next wave as usual, copy the original study and choose to Share codebooks with original study.
2. Load the data choosing to auto-code text responses.
3. Open the question(s) in Ascribe Coder (be sure the coding source reflects all the responses that need to be coded).
4. Optional: Conduct manual coding of smaller/ easy to code responses/ Regular Expression coding etc.
5. Access AI Coder.
6. Choose the saved codebook from the Codebook drop-down.
7. Make sure to use the same AI processor as the trained codebook.
8. Toggle the uncoded only option.
9. Click OK.

**Clean-up Segments in AI Coder as described above and export to Ascribe Coder.**

1. Optional: Once finished cleaning up in AI Coder, you can save the changes to the existing codebook by clicking the Save icon. NOTE: It will only update the existing trained codebook if you type in the exact name of the saved codebook.
2. Export to Ascribe Coder by choosing the option to Update and keep the share(s). This option retains the share and adds any newly created codes to the shared codebook. &#x20;
3. Proceed with clean-up/ quality check in Ascribe Coder and deliver data.

**Some Notes:**

* If you start without a codebook (in the second wave), the codebook properties of the trained codebook will remain intact, but a share will not be established.
* If you append to an existing codebook, any codes that already exist in Ascribe Coder will remain untouched, and all AI Coder codes will be appended to the existing codes. Properties from the trained codebook will be retained.
* If you create a new codebook for just the analyzed question(s), the share will be severed with any questions outside of your coding source, and the properties of the original trained codebook will be retained.
