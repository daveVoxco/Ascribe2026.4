# Charts and Tables Selection

In this dialog, you can select the types of visuals to display.

<figure><img src="../../.gitbook/assets/image (24).png" alt="" width="563"><figcaption></figcaption></figure>

**Location:**

The Chart options button is available in the main toolbar when you are in Visualize ( [ai-coder-visualize.md](ai-coder-visualize.md "mention")) mode.

<figure><img src="../../.gitbook/assets/image (25).png" alt=""><figcaption></figcaption></figure>
