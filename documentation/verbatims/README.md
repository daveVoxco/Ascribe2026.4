# Verbatims

Ascribe has several ways for handling verbatims, typically based on the coding task at hand.

[**Ascribe Coder**](../ascribe-coder/) — Code one verbatim at a time or code multiple verbatim at once; abilities to search and manage the codes and responses.

[**Code Verbatims using Phrase Analyzer II**](../phrase-analyzer-ii/) — Allows for coding short responses and building codebooks.

[**Multi-Media Coding**](multi-media-coding.md)—Ascribe supports coding from images and sound files. Coding from images is designed for scanned paper surveys, where the images are pictures of the handwritten responses.

[**Edit Verbatims**](edit-verbatims/)— You can edit both the respondents and the responses in a variety of ways.

[**Translate/Transcribe Verbatims**](translate-transcribe-verbatims.md)— Ascribe supports the translation of data into many languages and is completely Unicode compliant. Ascribe also supports the transcription of verbatims from both visual and sound files.

[**Filter – Set a Response Filter**](filter-set-a-response-filter.md)— You can set a filter to view only those responses that meet your criteria. For example, you may want to see just the respondents that answered "Yes" to a previous question.
