# Multi-Media Coding

Ascribe supports coding from images and sound files.

Coding from images is designed for scanned paper surveys, where the images are pictures of the handwritten responses. The user can code the image in Ascribe Coder. A small image displays; click it to enlarge the image.

Coding from sound files is designed for working with voice files from IVR systems.

The user can also code sound files in Ascribe Coder. Click the provided link in the response pane.

## Transcribe IVR and Image Files <a href="#minitocbookmark2" id="minitocbookmark2"></a>

_Navigate: Transcriber/Transcribe/Right-click study/Select Questions/Right-click question/Select Transcribe_

Most users find it helpful to transcribe responses from IVR and image files prior to coding them. You can do transcription from the Transcribe page.
