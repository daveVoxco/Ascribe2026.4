# Auto Code Options

This dialog has additional options for handling other specify text responses and shared questions. Note that these options ignore the minimum number of mentions in the Settings dialog.

Here are the options:

<table><thead><tr><th width="291.99993896484375" valign="top">Option</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top">Include Responses Containing Text</td><td valign="top">Allows for coding of responses containing text. Responses longer than 50 characters will not be coded.</td></tr><tr><td valign="top">Create Missing Codes</td><td valign="top">Creates missing codes; to include text responses, you must use the Include Responses Containing Text also.</td></tr><tr><td valign="top">Apply To All Shared Questions In This Study</td><td valign="top">If other questions in the study share this codebook, matched codes are applied.</td></tr><tr><td valign="top">Add Uncoded Segments To Notes</td><td valign="top">Adds uncoded segments to the Notes field.</td></tr></tbody></table>
