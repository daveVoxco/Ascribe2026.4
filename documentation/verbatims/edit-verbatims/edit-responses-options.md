# Edit Responses Options

The dialog has these options:

<table><thead><tr><th width="214" valign="top">Option</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top">Enable Automatic Translation</td><td valign="top">Select this option to allow automatic translations on this page; if it is not selected, the Automatic Translations button will not be active.</td></tr><tr><td valign="top">Allow Verbatim Editing</td><td valign="top">Select this option if you want to change verbatim; leave it blank if verbatim should not be changed. When you use this option, a Text (Editable) column displays. When you make changes in this column, the changes are applied to the Text (Read Only) column when you press Enter or Tab or move the cursor from the field. To have this option stick for each session, select Allow Verbatim Editing by Default on the<a href="../../get-started/customization-features/user-options.md"> User Options</a> page.</td></tr><tr><td valign="top">Allow Direct Editing of Text Fields</td><td valign="top">When selected, allows one-click editing of text fields; this option sticks from session to session. When direct edit is on, use the arrow keys to move to the next character in the text.</td></tr><tr><td valign="top">Interactive Spell Check and Language</td><td valign="top"><p>Select this option if you want to spell check a field after you've entered data. Once selected, then choose the language that the spell checker should use.</p><p>When using this option, a red line displays under any misspellings. Right-click the misspelling and use the menu to either correct the text or add it as a correct spelling to the account or user dictionaries.</p></td></tr><tr><td valign="top">Apply to Duplicates</td><td valign="top"><p>Options are:</p><ul><li>None (no duplicates will be changed)</li><li>Blank (only translations/transcriptions/notes that are blank will have duplicate information entered)</li><li>Not Blank (only translations/transcriptions/notes that are not blank will have duplicate information entered)</li><li>All (whenever a duplicate verbatim is found, the same translation/transcription/note will be entered).</li></ul><p><strong>Ignore case of Verbatim</strong> - when selected, the case of the verbatim will not be considered when identifying duplicates.</p><p><strong>For Displayed Responses Only</strong> - when selected, only the displayed responses are affected when applying duplicates.</p></td></tr><tr><td valign="top">Use Grid Paging</td><td valign="top"><p>Select this option if you want to have paging of responses. In the paging field, enter any number up to 10,000. This field indicates how many responses will display in the grid. Unselect the field if you don't want paging.</p><p>When selected, a paging field displays before the Question list. Click the forward button to move through the responses and the back button to move backwards. Keep in mind that the paging acts as a filter; the number of visible responses will depend on the paging field and any other filters you select.</p></td></tr></tbody></table>
