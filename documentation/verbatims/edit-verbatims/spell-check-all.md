# Spell Check All

The Spell Check All allows you to find and fix spelling errors. To correct verbatim, you must select Allow Verbatim Editing in the Options dialog. If the option is not selected, you can review the verbatim but not edit them.

The dialog has these fields:

<table><thead><tr><th width="234" valign="top">Field</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top">Target Field</td><td valign="top"><p>Choose from Verbatims, Translations, Transcriptions, or Notes.</p><p>To correct verbatims, you must select Allow Verbatim Editing in the Options dialog. If the option is not selected, you can review the verbatim but not edit them.</p></td></tr><tr><td valign="top">Language</td><td valign="top">Click the drop-down arrow to select the language dictionary. The spell check process happens automatically according to the selected language. The misspellings are highlighted with a red wavy line.</td></tr><tr><td valign="top">Sort Language List in English</td><td valign="top">When checked, this option sorts the language dictionary list by English names of the languages.</td></tr><tr><td valign="top">Account Dictionary</td><td valign="top">Use this option to add a word to the account dictionary, which is used for all users on an account. (Note: There is an account dictionary for each language. For example, if French is the selected language, you would be adding a word to the account dictionary for French.)</td></tr><tr><td valign="top">User Dictionary</td><td valign="top">Use this option to add a word to the user dictionary. The user dictionary is per user ID and is not shared to everyone on an account. (Note: There is a user dictionary for each language. For example, if French is the selected language, you would be adding a word to your user dictionary for French.)</td></tr></tbody></table>

When a misspelling is found, the word is highlighted with a red wavy line. Right-click the word to see these options:

<table><thead><tr><th width="272.6666259765625" valign="top">Option</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top">Add To Dictionary</td><td valign="top">Allows you to add the word to the Account Dictionary or the User Dictionary.</td></tr><tr><td valign="top">(Suggestions)</td><td valign="top">The suggested corrections are listed below the line. Click on the correction to have it replace the misspelling.</td></tr></tbody></table>

You can manually correct the misspelling by clicking the response and editing it.

Once a misspelling is corrected, it is removed from the dialog.

## Grid

The columns in the grid of responses are controlled through the [Table Manager](../../study/table-manager.md). Choose what fields display, such as respondent ID, question ID, verbatim, text, and verbatim length.
