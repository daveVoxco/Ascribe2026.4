# Edit Responses II

On this page, you can view and edit all of the responses to a question. All Edit Responses functions can take place before, after, or during coding. The Edit Responses page is designed to allow you to enter translations or transcriptions quickly for many responses.

## Page Layout

![](https://static.goascribe.com/Help/Edit_Responses_II_layout.jpg)

The page has this format: black title bar with a toolbar underneath with the study ID and number of displayed responses, the question drop-down, followed by the grid of responses. The question drop-down displays the number of questions in the source and can be expanded and collapsed. When expanded, the question ID and label display.

## Grid

The columns in the grid of responses are controlled through the [Table Manager](../../study/table-manager.md). Choose what fields display, such as respondent ID, question ID, verbatim, translation, transcription and notes. You can also show the coded status and applied codes for the verbatim. You can show the reviewed status of all fields.

A Verbatim Length column is also available, which allows you to sort the grid by length.

Users can copy/paste from the enabled fields by using CTRL/C and CTRL/V.
