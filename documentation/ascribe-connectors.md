# Ascribe Connectors

The Ascribe Connectors page allows users to retrieve studies from the APIs (application program interfaces) of specific data collection software and load the studies into Ascribe. The Ascribe Connectors page lists the available data collection software and provides a way to link to the API.

&#x20;

Users will need to work with the Ascribe Support team to establish the connection between Ascribe and the data collection software. Users also need to have licenses and permissions to use the API of the data collection software.

### Configure the Connection <a href="#minitocbookmark2" id="minitocbookmark2"></a>

The first step is to configure the software to work with the API of the data collection software. Once the connection is configured, you do not have to do this step again.

&#x20;

Click the Configure link in the Configured column. This action opens the Authentication dialog. Enter the appropriate information such as user ID, password, and service URI. (These fields are provided by the data collection administration.) The user credentials need to have permission to use the API and permission to access the study.

&#x20;

When the connection is established, the page displays the Study View, which lists available studies. The studies must be launched/contain data in order to display.

### Study View <a href="#minitocbookmark3" id="minitocbookmark3"></a>

To load a study, click the Connect to Ascribe link in the Ascribe Study ID column. A dialog opens with the Ascribe Study ID and the list of questions. Select the questions and click the Import button. A message displays indicating that the process is working, and then indicating the process is complete.

&#x20;

Once a study is imported, click the study ID to navigate to the study.

### Load More Data <a href="#minitocbookmark4" id="minitocbookmark4"></a>

To load more data to a study, click the study ID and select Import more data.
