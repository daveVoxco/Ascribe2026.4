# Questions in Progress

![](https://static.goascribe.com/Help/Questions_in_Progress_\(New\).jpg)

The Questions in Progress (New) page displays the questions for a study. A question will appear in this list only if the Code task is checked in the Question Properties dialog or on the Tasks field on the Questions page.

The page has this format: black [title bar](questions-in-progress.md#minitocbookmark2) with a [toolbar](questions-in-progress.md#minitocbookmark3) underneath, followed by the [question type filters](questions-in-progress.md#minitocbookmark4) and the [grid](questions-in-progress.md#minitocbookmark5) of questions.

## Question Type Filters <a href="#minitocbookmark4" id="minitocbookmark4"></a>

The question type filters are below the toolbar to allow for easy access since these filters are so widely used. Each question type is listed. Click a button to toggle on/off the study status. When a button is off, the button turns white with a color outline. There is a slight delay after a button is clicked to allow you to select/deselect another button before the page refreshes. The delay should be very minor.

The other columns each have a filter which displays when you hover over the column header.
