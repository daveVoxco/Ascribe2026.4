### More About Tooltips

Cells with an available tooltip show a question mark on the cursor when hovering. The gesture required to display the tooltip is set in the Table Manager on the Rows tab.

When a tooltip is displayed using Hover or Ctrl-Hover, the action of moving the pointer across a cell border triggers the display of the tooltip. When Ctrl-Hover is used, the Ctrl key must be depressed while the pointer is moved into the cell.

By default, tooltips vanish when the pointer is moved outside the cell. The tooltip can be made “sticky” by holding the shift key while the pointer is moved into the cell. This works when tooltips are displayed on Hover or Ctrl-Hover (for Ctrl-Hover both the Ctrl and Shift keys must be depressed when the pointer moves into the cell). A “sticky” tooltip will remain displayed until you click outside of it.

When a tooltip is displayed by a middle mouse button click, you can set the Pin option in the Table Manager to have it be always “sticky”. This allows the user to display “sticky” tooltips with a middle mouse click and “normal” tooltips using the other ways to display tooltips.
