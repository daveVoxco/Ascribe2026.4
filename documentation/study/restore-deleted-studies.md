# Restore Deleted Studies

This dialog allows users to restore recently deleted studies. Recently deleted studies are available until weekly maintenance is run, which removes the studies from the account. For example, if the user deletes a study on June 1, and weekly maintenance is run June 5, the user can restore the study any time before June 5. After June 5, that study is no longer available for restore using this option.

The dialog has this information:

<table><thead><tr><th width="225.3333740234375" valign="top">Column</th><th valign="top">Description</th></tr></thead><tbody><tr><td valign="top">Selection Column</td><td valign="top">Select a study by clicking the checkbox</td></tr><tr><td valign="top">Created Date</td><td valign="top">Self-explanatory</td></tr><tr><td valign="top">Study ID &#x26; Name</td><td valign="top">Displays study ID and name</td></tr><tr><td valign="top">Questions Count</td><td valign="top">Number of questions in the study</td></tr><tr><td valign="top">WARNING/Weekly Maintenance Date</td><td valign="top">This message displays below the grid of studies and gives the date and time that weekly maintenance will be run.</td></tr></tbody></table>

Click Restore to restore the studies. They are returned to the Studies page with a status of under construction.
