# Questions Page

<figure><img src="../../.gitbook/assets/image (308).png" alt=""><figcaption></figcaption></figure>

The Questions page displays the questions for a study. The page has many options for working with the questions. You can get information about the questions, such as the question text and how much has been coded. Also, you can add and edit questions from this page

The page has this format: black [title bar](questions-page.md#minitocbookmark2) with a [toolbar](questions-page.md#minitocbookmark3) underneath, followed by the question type filters and the [grid](questions-page.md#minitocbookmark5) of questions.

## Question Type Filters

The question type filters are below the toolbar to allow for easy access since these filters are so widely used. Each question type is listed. Click a button to toggle on/off the study status. When a button is off, the button turns white with a color outline. There is a slight delay after a button is clicked to allow you to select/deselect another button before the page refreshes. The delay should be very minor.

The other columns each have a filter which displays when you hover over the column header.

The basic types of questions include open, closed, other specify, value, and data.

Every question type may be coded in Ascribe. However, **data** questions usually are not coded and often do not appear in the question lists. Data questions are used usually for output.

**Open** questions are answered with verbatim text. This text is entered in by the respondent over the Internet, described verbally to a phone operator, or written. Open-ended questions also can be verbally recorded or hand-written and scanned (image files).

**Closed** questions limit the responses to a fixed set of answers. A closed-end question can help you understand a respondent’s answer to an open-ended question. For example, the open-ended question may be: "You said x about y, why did you say that?", where x and y are answers to a closed-ended question.

When you load a closed-ended question, the data can be automatically coded if the codebook for the question has been defined and the loaded data matches the code values in the codebook. Here's how it works:

* Define the question ID to match the question ID in the data to be loaded.
* Create a codebook that matches the codes in the data to be loaded. For instance, if you have a five-number rating scale on a purchase intent question, then your codebook should use the same numbers.
* After you build the codebook, load the data, and it will be automatically coded. Ascribe matches the codes in the incoming data to those in the codebook.
* If you load the data before you create a codebook, you can still automatically code the data. Create a codebook, then right-click the question, and select Auto-apply codes.

**Other specify** questions may have both open-ended and closed-ended data. The closed-ended data can be automatically coded when the data is loaded, if the codebook is set up correctly. However, the verbatims for other specify questions often contain multiple responses. When Ascribe finds the same question ID and respondent ID combination in a load file, the data is concatenated and separated with the vertical bar symbol (|). These responses will not be automatically coded.

**Value** questions have a numeric response which will be coded as a range.

## Change the Page with Mouse Gestures <a href="#minitocbookmark6" id="minitocbookmark6"></a>

Here are mouse gestures you can use to change the layout of the page:

* Drag column border in header: resize column to left of mouse
* Double-click column border: resize column to fit content
* Drag column header within grouped columns: move column to new location in group
* Drag column header to Row Groups: group rows by that column
* Drag row border in header: resize all rows
* Click column header: sort grid by that column, toggle sort direction if already sorted
* Ctrl-click sorted column header: clear sort of that column
* Click filter icon in column header: open filter drop-down
* Right-click in row: select clicked cell, open context menu
* Click in row header: select left-most cell, open context menu
* Click checkbox in row header: toggle selection of row for multi-row operations
* Shift-click checkbox in row header: select rows to last row selected
* Click checkbox in header above row checkboxes: toggle selection of all rows
* Click count in header above row checkboxes: clear selection of all rows
* Click in buttons in Shortcut column: perform action
* Click hamburger at bottom row of top left cells: open Table Manager
* Click on count above hamburger at bottom row of top left cells: clear all filters

## Keystroke Shortcuts <a href="#minitocbookmark7" id="minitocbookmark7"></a>

The following are keystroke shortcuts for the page:

* Space: Start editing current cell or toggle checkbox
* F2: Start editing current cell
* Left/Right arrows: Move current cell to left or right
* Up/Down arrows: Move current cell up or down
* Alt + Up/Down: If the current cell has a drop-down list of options, toggle visibility of the list
* Page Up/Page Down: move the current cell up or down by the number of visible rows
* Home/End: Move the current cell to the start/end of current row
* Ctrl + Home/End: Move the current cell to the first or last row and column
* Esc: Cancel current cell edit operation
* Tab/Shift Tab: Move the current cell right or left. If cell is being edited, commit edit.
* Enter: If cell is being edited, commit edit
* Delete/Backspace: If cell is editable, delete cell contents
