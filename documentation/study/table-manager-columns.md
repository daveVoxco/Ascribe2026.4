# Table Manager - Columns

The Columns tab allows you to select which columns display on the page.

<figure><img src="../../.gitbook/assets/image (87).png" alt=""><figcaption></figcaption></figure>

Checked columns are visible in the grid.

Check a column group check box to toggle visibility of all columns in the group.

The columns will display in the order found in the Table Manager/Columns tab. The sub-headers in each section can be rearranged through mouse gestures.

The first column of the grid (below the Table Manager icon) is blank to allow a left-click menu (appropriate for mobile devices).

Each column has these options:

* **Filter** - Each column (except [Study Status](studies-page.md#study-status-filters)) has a filter which displays when you hover over the column header. When a filter is active, the column header in the grid and in the Columns tab of the Table Manager are highlighted yellow. When a filter is active, the Table Manager hamburger icon also has a yellow highlight and the number of filters displays above it. Click that number to remove all filters. When a column with an active filter is hidden, the filter is not removed (the Table Manager icon remains highlighted yellow to alert you that a filter is still applied.)
* **Sort** - Click the column header to sort the grid by that column; toggle sort direction if already sorted. Ctrl/click the sorted column header to clear the sort of that column. If a sorted column is hidden, the sort is removed. The column header that is used for the sort is highlighted in light green.

Most column headers are self-explanatory. Here are a few for the Studies page that might not be obvious:

* Study/Loads - The number of loads that have been done to this study, including loads that resulted in not adding any responses.
* Questions/Count - The number of questions in the study
* Questions/Open, Other specify, Closed - The number of questions of these types in the study
* Questions/Responses - The total number of responses in the study, regardless of the state of the Code task
* Coding/Questions - The total number of questions marked with the Code task
* Coding/Responses - The total number of responses in the study, for those questions marked with the Code task
