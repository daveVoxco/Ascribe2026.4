### View <a href="#minitocbookmark5" id="minitocbookmark5"></a>

This tab displays the codebook along with the number times a code has been used.

### Singletons <a href="#minitocbookmark6" id="minitocbookmark6"></a>

This tab displays existing singleton codes and allows you to make all codes singleton or clear singleton from all codes. For more information, see [Singleton](../ascribe-coder/codebooks/edit-code.md).

### Unshare, Share To, and Share From <a href="#minitocbookmark7" id="minitocbookmark7"></a>

When questions **share** a codebook, there is only one codebook. If you make a change to the codebook, that change will be seen in all questions that share the codebook.

When you **copy** a codebook, you create a new, separate codebook. If you copy a codebook from question A to question B, the codebooks are initially identical. However, there are two codebooks, and they are separate from each other. If you change the codebook for question A, the codebook for question B remains unchanged since it is a separate codebook.

&#x20;The Unshare tab allows you to remove the share between questions.

&#x20;The Share To tab allows you to establish a share between questions in this study or copy codebooks to selected questions.

&#x20;The Share From tab allows you to share or copy codebooks from questions in this study, another study or from account codebooks.&#x20;

## Related Questions <a href="#minitocbookmark8" id="minitocbookmark8"></a>

Related questions allow coders to see the response to another question while in Ascribe Coder. For example, you have an open-ended response, and you would like to see the closed-ended response that relates to this question.

To set related questions, select the appropriate question(s) and click Apply.

## Coders <a href="#minitocbookmark9" id="minitocbookmark9"></a>

The Assigned tab displays a list of all users with Coder privilege on the left, and the assigned coders on the right. You can assign coders by clicking the check box next to the user name.

The Coded By tab displays the codebook with the user name who applied the code. Click a code to see the responses that received the code and the coder that applied the code.&#x20;

## Samples <a href="#minitocbookmark10" id="minitocbookmark10"></a>

The View tab displays the samples that contain responses from this questions. You can delete a sample by selecting it and clicking the confirmation check box and then clicking the Delete Selected Samples button. This operation will only delete samples where you are the owner.

The Create tab allows creation of a new sample. All questions that share the codebook and contain responses are shown at the bottom. Select one or more questions and specify the required options for the sample, and then click Create Sample. This action will switch you to the View tab with the new sample selected.

## Loads <a href="#minitocbookmark11" id="minitocbookmark11"></a>

The top table lists the loads for the study. In the case of automated loads by FTP, many study loads will result in no responses loaded. The table can be filtered by the Questions or Responses Loaded column if desired to show only those loads that added responses. The table allows selection of one or more loads by checking the row selector checkbox.

The lower table lists the questions that had responses loaded in the loads selected in the upper table. If more than one load is selected in the upper table, there may be more than one load displayed in the lower table for a given question, up to one for each study load selected. One or more question loads can be deleted by selecting them and clicking Delete Selected Question Loads. If you select all questions, then the entire load is deleted (meaning all responses for the load are deleted, the load will still appear in the upper table, but with no responses loaded).
