# Table Manager - View

The Table Manager/View tab allows you to save display settings so you can have different views of the page. All display settings, except for user settings, for various options, are saved. User settings (<img src="https://static.goascribe.com/Help/user_setting_icon.png" alt="" data-size="line">) are for all tables/grids and do not change when the View is switched or reset to defaults.
