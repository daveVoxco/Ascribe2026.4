# Table Manager - Sort

To sort the grid, click a column header. The column header is highlighted green. Click the column header to change direction of the sort, and the header is highlighted orange. To remove the sort, Ctrl/click the header.

<figure><img src="../../.gitbook/assets/image (89).png" alt="" width="368"><figcaption></figcaption></figure>

{% hint style="warning" %}
#### Important

Changes made to options with the user settings icon (<img src="https://static.goascribe.com/Help/user_setting_icon.png" alt="" data-size="line">) will be applied to all grids.
{% endhint %}
