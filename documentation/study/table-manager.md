# Table Manager

The Table Manager allows you to customize the page, by choosing columns and other options. Some options have this user setting icon next to them, which means setting this option will apply to all grids.&#x20;

<figure><img src="../../.gitbook/assets/image (85).png" alt=""><figcaption></figcaption></figure>

{% hint style="warning" %}
#### Important

Changes made to options with the  user settings icon (<img src="https://static.goascribe.com/Help/user_setting_icon.png" alt="" data-size="line">) will be applied to all grids.
{% endhint %}

**Location**:

The Table Manager icon (<img src="https://static.goascribe.com/Help/Table_manager_icon.png" alt="" data-size="line">) is in the top left cell of grids.

<figure><img src="../../.gitbook/assets/image (86).png" alt=""><figcaption></figcaption></figure>
