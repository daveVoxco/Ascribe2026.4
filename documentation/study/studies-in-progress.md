# Studies in Progress

_Navigate: Coder/Studies in Progress_

A study displays on this page only if both of the following are true: the study status is In Progress, and the Code task is checked in the Questions Properties for at least one question in the study.

## Page Layout <a href="#minitocbookmark2" id="minitocbookmark2"></a>

![](https://static.goascribe.com/Help/Studies_in_Progress_New_UI.jpg)

The page has this formation: black [title bar](studies-in-progress.md#minitocbookmark3) with a [toolbar](studies-in-progress.md#minitocbookmark4) underneath followed by the [grid](studies-in-progress.md#minitocbookmark5) of studies.
