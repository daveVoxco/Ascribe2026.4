# AI Coder – Trained Codebook Process for Trackers

The trained codebook can then be used to code future waves of a tracker study with accuracy and consistency.

## STEP 1:  Train original codebook with manually coded data

{% stepper %}
{% step %}
Open question(s) in Ascribe Coder (be sure the coding source reflects all responses needed to train the codebook).
{% endstep %}

{% step %}
Access AI Coder.
{% endstep %}

{% step %}
In the “Options” dialog, choose **Train Codebook** from **Codebook** drop-down.
{% endstep %}

{% step %}
Chose to use either Generative or Non-Generative AI.

If using non-generative make sure the split characters and words work for this project.

If using Generative decide if you want to use a prompt. Remember this prompt as you will want to use it on future projects where the trained codebook will be applied.
{% endstep %}

{% step %}
Choose **OK**.

<figure><img src="../.gitbook/assets/image (279).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

## STEP 2: Clean-up and Save

{% stepper %}
{% step %}
Clean-up Segments in AI Coder and Save the trained codebook.

{% hint style="info" %}
### Note

Original/ trained codes cannot be changed; all original codes and nets have borders; segments associated with a code can be removed or moved; new codes and/or nets can be added; new codes will not have borders and can be edited/ combined.
{% endhint %}

<figure><img src="../.gitbook/assets/image (283).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
(Optional) **Auto code others** to create codes that can be combined into existing\
codebook



<figure><img src="../.gitbook/assets/image (284).png" alt=""><figcaption></figcaption></figure>

* Check others for easy to categorize segments and move into  \
  appropriate code
* Check segments associated with codes and remove any obscure  \
  segments; move any incorrectly classified segments to the proper code
{% endstep %}

{% step %}
Save the codebook.

<img src="../.gitbook/assets/image (285).png" alt="" data-size="original">

Once the codebook is saved, it is available to use for coding other projects.
{% endstep %}
{% endstepper %}

## STEP 3: Use a trained codebook for the next wave of a tracker study

{% stepper %}
{% step %}
Set-up the next wave as usual, copy the original study and choose to **Share codebooks with original study**.

<figure><img src="../.gitbook/assets/image (281).png" alt="" width="563"><figcaption></figcaption></figure>
{% endstep %}

{% step %}
Load the data choosing to **auto-code text responses**.
{% endstep %}

{% step %}
Open the question(s) in Ascribe Coder (be sure the coding source reflects all the responses that need to be coded)
{% endstep %}

{% step %}
(Optional) Conduct manual coding of smaller/ easy to code responses/ Regular Expression coding etc.
{% endstep %}

{% step %}
Access AI Coder.
{% endstep %}

{% step %}
Choose the saved codebook from the **Codebook** drop-down.
{% endstep %}

{% step %}
Make sure to use the same AI processor as the trained codebook.
{% endstep %}

{% step %}
Choose the **uncoded only** option.

![](<../.gitbook/assets/image (282).png>)
{% endstep %}
{% endstepper %}

## STEP 4: Clean-up Segments in AI Coder and export to Ascribe Coder

{% stepper %}
{% step %}
(Optional) **Auto code others** to suggest new codes.

Check others for easy to categorize segments and move segments to appropriate code.

Check segments associated with codes and remove/ move segments to other codes as needed.

Once finished cleaning up in AI Coder you can save the changes to the existing codebook by hitting the “save” icon.

{% hint style="info" %}
### Note

It will only update the existing trained codebook if you type in the exact name of the saved codebook.
{% endhint %}
{% endstep %}

{% step %}
Export to Ascribe Coder choosing the option to **Update and keep the share(s)**.

This option retains the share adding any newly created codes to the shared codebook.

<figure><img src="../.gitbook/assets/image (280).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
Proceed with clean-up/ quality check in Ascribe Coder and deliver data.
{% endstep %}
{% endstepper %}

{% hint style="info" %}
#### Notes

* If you start without a codebook (in the 2nd wave), the codebook properties of the trained codebook will remain intact, but a share will not be established.
* If you append to existing, any codes that already exist in Ascribe Coder will remain untouched, all AI Coder codes will be appended to the existing codes. Properties from the trained codebook will be retained.
* If you create a new codebook for just the analyzed question(s), the share will be severed with any questions outside of your coding source, the properties of the original trained codebook will be retained.
{% endhint %}
