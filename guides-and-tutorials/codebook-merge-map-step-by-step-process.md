{% step %}

{% step %}
### Select Target Codebook / Source Codebook.

_**Target Codebook -** the codebook that is the final result of the merge. It displays on the left side of the screen._\
&#xNAN;_**Source Codebook -** the codebook that contains codes to be merged; it will be shared with the target codebook at the end of the process. It displays on the right side of the screen._

* The left side of the screen **(Target Codebook)** contains the list of available Codebooks and Questions. The right side of the screen **(Source Codebook)** contains the list of available Codebooks and Questions. Use the search functionality or browse through the folders to find the codebook that you want as your target/source.
* The available codebooks are displayed by Question **(separate codebook for each question)** and Codebook **(one codebook for shared questions and separate codebook for questions that are not shared)**. Click the drop-down arrow next to the **Questions/Codebooks** folder to view the codebooks. **Note:** Shared codebooks are highlighted in yellow.
*   After you locate the codebook you want, click the codebook to load it as your target/source.

### Match Codes(Auto Match, Manual Match and Add Source Code to Target Codebook).

**Auto Match Codes (Match Codes button)**

* The Match Codes button is used to "Auto Match" codes by Description, Input ID,  \
  Output ID and more.
* Click the Match Codes button to display the Codebook Match Criteria dialog.
  * Choose one or more criteria to match and then click the OK to begin the match    \
    process.
* The Match Codes dialog will appear when the auto-match process is complete. The  \
  dialog displays the number of matches found and the number of unmatched codes  \
  remaining. Click OK to close the dialog.

**Manual Match Codes**

* To match a code manually, first click the Target code you want to match
* Once you have a target code selected, you can select a Source code to match by  \
  clicking the code description.

**Add Source Code to Target Codebook**

* You can add a Source code to the Target codebook, automatically matching it in  \
  the process.
* Right-click a Source code then select “Add to target codebook”

{% endstep %}

{% step %}
### Merge/Map (Save to Target Codebook).

* Once all of the codes have been matched, the Merge/Map can now be executed.
* Click the Save to Target Codebook button to continue.
* When the Questions to Merge dialog appears, select “Source” questions that will be merged into the “Target” codebook’s questions (s). Click the OK button to continue.
* The Confirmation dialog will appear requiring the user to type “OK” in the text box to  \
  proceed. Click OK button to continue  .
* The Merge Complete dialog will appear. Click OK button to end the merge process.
