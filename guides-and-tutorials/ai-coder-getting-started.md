# AI Coder: Getting Started

AI Coder is Ascribe’s codebook builder and theme extractor. It extracts ideas (segments) from\
responses and groups them into codes. The user can either export the results into Ascribe Coder or\
use the Visualize and ASK modules available within AI Coder.

## Generative or Non-Generative AI?

Generative AI summarizes the main idea(s) from each response into segments to create a\
codebook, whereas non-Generative AI uses split characters and split words to manually segment\
the responses prior to grouping into codes.

As a rule, Generative AI is most useful when analyzing Open End responses, while Non-Generative\
AI is best used for brand/single response/keyword coding.

Theme Extractor for Codebook Building/Coding or\
Clustering AI Codebook Building/Coding?
---------------------------------------

Theme Extractor is the default and simplest option when running your analysis. It leverages\
generative AI built on top of Ascribe’s algorithms and rule sets to provide results. Theme Extractor\
will provide the largest coded percentage as well as a shorter codebook.

Turning Theme Extractor off allows the user to control all parts of the analysis on the individual\
level. This option is recommended for users who are already familiar with AI Coder functionality.

## Running AI Coder

1. Open a question in Ascribe Coder.
2. Unlock the codebook.
3. Click the AI Coder icon.
4. Once the Analyze window comes up, choose between Generative or Non-Generative. Non-Generative is on by default.
5. When ready click on the “Go” button.

## Working in AI Coder

1.  **Review the percentage coded and number of codes created once the analysis is done. Do you need more codes? You might experiment with the Analysis settings and re-analyze to get more data coded.**

    1. Use the Analyze button to bring up the analysis options.
    2. Edit the data context to control the idea extraction and codebook building.
    3. Alternatively use the Initial Codes Min. Proximity value to control the initial coding.
       1. Raising the Initial Codes Min. Proximity value will code less data but will          \
          create more concise codes.
       2. Lowering the Initial Codes Min. Proximity value will code a larger portion of          \
          the data and create somewhat more general codes

## Uncoded Segments

1. By default, the Uncoded Segments code displays uncoded segments belonging to partially   \
   coded responses. Enable the checkbox toggle on the Uncoded Segments code to display   \
   uncoded segments which are part of completely uncoded responses.
2. Use any of the following tools to review and upcode the Others
   1. Use “Keywords” to manually identify segments that fit existing codes or add new      \
      codes.
   2. Click on the Autocode Others icon to automatically generate additional codes from      \
      the segments in Others.
   3. Use the Help Code Others icon to bring up the Coding Suggestions window for the      \
      Others.
